# Data license decision — V4 Cirsium aggregate results

**Chosen license for the original, author-controlled aggregate analytical outputs:**
Creative Commons Attribution 4.0 International (CC BY 4.0).
SPDX identifier: `CC-BY-4.0`.
Legal code: https://creativecommons.org/licenses/by/4.0/legalcode

Scope of the choice: original statistical summary tables, fitted coefficient
summaries, aggregate test statistics, original analytical summaries and
original numerical data visualisations **to the extent these are owned by the
author(s) and legally redistributable**. Users must give appropriate attribution,
provide the license link and indicate changes.

This permission does **not** override third-party rights. It does not grant
CC BY 4.0 to original iNaturalist photographs or metadata, exact coordinates,
CHELSA / WorldClim raster products, WCVP taxonomic databases, external model
weights, or materials independently subject to other licenses. Taxonomic names,
source credits and provenance remain attributed to their sources.

Original source code and its software documentation retain the included
MIT license; see `LICENSE` and `NOTICE.md`. Scientific source data and code are
distinct from the original, derived analytical outputs.

**Pre-release warning:** This ZIP is an unpublished working release candidate.
The intended CC BY 4.0 data license was approved as a *policy* on 2026-10-30;
creators, actual file-by-file rights clearance, reviewer anonymity and final
Zenodo publication remain to be approved separately. Do not treat the
candidate, this document or a GitHub source link as a published deposit/DOI.
