# Chapter 1 GEB scope freeze — 2026-09-12

## Decision

Chapter 1 is now treated as a **GEB-targeted macroecological/comparative paper**, not as an open-ended analysis platform.

The current v3 contribution is already conceptually stronger than a collection of endpoint-by-environment regressions. Its main result is the scale-dependent organization of biologically aggregated capitulum traits:

> **Biological modules persist across within-taxon and among-taxon scales, while integration strength increases and detailed relation geometry is only partly conserved among taxa.**

The environmental results are retained as two pre-existing ecological anchors rather than expanded into a larger post-hoc search surface.

## Frozen evidence hierarchy

### Broad atlas layer

The frozen v2 spatial atlas contains **46,276 observations / 259 taxa** and supplies the broad macroecological trait–environment context. This layer should not be described as the direct sample size for the complete within/among integration test.

### Direct scale-comparison layer

The strict common cohort for the nine biological constructs contains **1,734 observations / 42 taxa**. This is the inferential cohort for the direct within-vs-among integration comparison.

Canonical results:

- within–among relation-matrix alignment: **rho = 0.439125**, QAP **P = 0.0041**;
- taxon-bootstrap alignment median: **0.31210**, 95% interval **0.01708–0.53517**, **97.9% positive**;
- module cohesion: within-taxon **P = 0.0013**, among-taxon **P = 0.0365**;
- observed median RV: **0.002238 within** vs **0.043212 among**;
- **33/36** construct relations are stronger among taxa;
- 1,000-bootstrap median-RV difference (among − within): median **+0.065928**, 95% interval **+0.038197 to +0.119048**, positive in **100%** of replicates;
- frozen ecological anchors: floral chroma × shortwave radiation (**beta = -0.345372**) and presentation angle × annual precipitation (**beta = +0.304359**), both surviving the full construct-level robustness chain including historical tree sensitivity.

## Main-paper claim boundary

### Claims to foreground

1. Public biodiversity photographs can support repeated, continuous, multi-trait phenotypic measurements when observation units, assessability, provenance and technical limitations are explicitly retained.
2. Capitulum traits form detectable biological modules within taxa and among taxa.
3. The detailed relation geometry is partly conserved across scales, but overall visible-phenotype integration is stronger among taxa.
4. Two pre-frozen ecological associations remain robust after biological reaggregation and the current sampling/spatial/historical sensitivity chain.

### Language to avoid

Do not claim from the current data alone:

- a universal "scale-dependent integration law";
- genetic or developmental modularity;
- plasticity or reaction norms;
- causal environmental effects;
- gravity-referenced physical orientation accuracy;
- calibrated physical flower colour;
- unbiased image sampling;
- that 46,276 observations / 259 taxa are the direct common-cohort integration sample.

Prefer **scale-dependent integration pattern**, **scale-dependent reorganization**, or **partially conserved cross-scale geometry**.

## What still belongs to Chapter 1 before submission

Only work that changes **submission validity, reproducibility, or interpretation safety** remains in scope. Examples include:

- independent measurement-validity checks that are already required by the manuscript claim boundary;
- unresolved systematic camera-roll / orientation limitations where they materially affect interpretation;
- unresolved colour-error propagation or equivalent validity limits where evidence exists to close them;
- consistency checks across manuscript, figures, tables, captions, frozen artifacts and runbooks;
- journal formatting, reporting completeness, archive/DOI and submission package checks.

These are **submission-readiness tasks**, not attempts to manufacture a higher-impact story.

## Explicit stop list for v3

Do not add analyses merely to increase apparent sophistication, including:

- additional climate or soil predictors without a preregistered manuscript need;
- alternative GAM/Bayesian/ordination/network formulations of already answered questions;
- additional integration metrics that do not test a distinct falsifiable alternative;
- more post-hoc construct regrouping;
- increasing the historical sensitivity tree count solely for optics;
- new endpoint-level searches after the current frozen multiplicity families;
- reinterpreting within-taxon covariance as plasticity or developmental mechanism.

A new analysis enters v3 only if it closes a named threat to the existing claim set or is required for reproducible submission.

## Route to a genuinely higher-tier successor

Moving beyond the current GEB-scale paper requires **new evidence, not more analysis of the same Cirsium image matrix**.

### Route A — independent lineage prediction test

Freeze a directional prediction from Chapter 1 before opening the new lineage data, for example:

> among-taxon integration is stronger than within-taxon integration while cross-scale relation geometry remains only partially conserved.

Then test the same construct-level prediction in an independently sampled plant lineage with an equivalent within/among design. A simple replication is not sufficient; the prediction and analysis contract should be fixed prospectively.

### Route B — direct mechanism

Measure a process capable of generating the scale transition, for example developmental covariance, genetic covariance, common-garden structure, functional trade-offs, or another directly observed mechanism linking within-taxon and among-taxon organization.

### Route C — theory plus independent prediction

Derive a quantitative prediction for when integration strength or geometry should change across scales, freeze it, and test it in independent data. This route is only distinct from A/B if the theory yields new directional or quantitative predictions rather than re-describing the observed Cirsium pattern.

## Operational rule

**Finish Chapter 1 as the sharpest defensible GEB paper. Do not hold submission hostage to an Ecology Letters upgrade.** Any independent-lineage or mechanistic extension should be developed as a successor study unless it already exists independently of the current image dataset and can be integrated without reopening the frozen Chapter 1 analysis surface.
