# Bの曲線の地域構造：直接診断（2026-11-27）
前のC（地域別平均差と分散の分解）は連続形質の記述であり、Bの条件付き一次・二次係数そのものを分解したわけではない。Bは既に地域内でマッチしたセル対のペア切片を持つため、単なる全球の無条件分布の混合とは異なる。今回の目的は曲線への寄与の地域偏りを診断し、両端の周辺頻度差が同じ対・地域に共存するかを記述すること。既存のP判定・気候応答の不確実性を維持し、新しい検定やモデル選択は行わない。

1. 既存の3形質・125区分・地域内マッチ・2気候定義・在来参照を変更しない。元24係数、元24の条件付きスコア検定Pおよび正スコア地域数、前回の分散ゲートを再現する。地域の符号・相殺・正負寄与の大きさと最大絶対寄与割合を、元モデルの他5項を調整した効率スコアで記述。スコアの符号は係数への寄与で、個別地域の選択勾配でも個別Pでもない。
2. 等セル対重みの元モデルと、同じ地域にあるセル対の重みを地域対数の逆数で調整した等地域重みのモデルを並べる。ペア内の両群の質量を等しくし、ペア切片をプロファイル、6項を維持。追加罰則や閾値調整なし、数値不適格なら未推定。新規Pなし。種×定義×3形質×2項を全報告し、曲線の形・係数差を記述する。等地域化は代表性を保証しない。
3. 同じ内側125区分の五分位周辺頻度を集約。各セル対の最低/最高五分位の新規−類似差の符号（減少・不変・増加の9組合せ）と、地域内で平均した差の符号を区別し、等セル対・等地域重みの両方で集計。両端増加（CV角度の候補）・両端減少（CA彩度の候補）の同時出現が、各対と地域集計でどう異なるかを検討する。等地域・等対の全五分位頻度も出力。周辺頻度の変化は調整済みのBの曲率と異なる推定対象。出力には地域ID・位置・観測単位を含めない。
4. 記述的結果から、空間的な異質性や地域重みへの感度、周辺の両端変化が同じ比較単位に現れるかを判断する。地域内でも同方向であっても、局所的選択や適応度の最適値、遺伝的分岐を同定できない。分散分解・気候予測の既存結果を否定しない。追加の閾値探索・有意性探索はしない。これをBの曲線の空間構造に関する最終診断とし、結果を確認してCの採否を決める。
