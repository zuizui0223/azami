# V5 S2　在来域と移入域の気候占有の重複

V5の全域比較に含まれる2種について、年平均気温・温度季節性・年降水量・降水季節性・日射を用いた。標高と花形質は使わない。各種で在来域と移入域の利用可能気候を等しく重み付けした共通PCAを作り、最初の2軸の密度格子を表示した。各分布域内の出現密度は利用可能な気候の頻度で補正してある。

青＝在来域だけの主要95%領域、橙＝移入域だけの主要95%領域、紫＝両方の主要95%領域。白色の格子でも低密度の出現があり得る。指標Dは80×80格子上で両域の正規化密度の小さい方を合計した値（0で重なりなし、1で同じ密度分布）。色面の面積比とは異なる。

|種|Schoener D|移入域の背景補正済み密度のうち、在来95%領域の外|在来域の背景補正済み密度のうち、移入95%領域の外|
|---|---:|---:|---:|
|C. arvense|0.474|18.8%|47.7%|
|C. vulgare|0.442|44.0%|7.9%|

解釈：全体のDは近いが、外側にある密度の方向は異なる。C. vulgare では移入先が在来域の主要気候から外れる割合が大きい。占有された気候の比較であり、繁殖上の利益や基本ニッチの拡大を示す指標ではない。
