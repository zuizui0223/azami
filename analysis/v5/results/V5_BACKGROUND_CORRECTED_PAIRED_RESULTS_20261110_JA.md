# V5：気候背景補正後の地域ペアDと頭花空間Dの対応（原本認証済み）

**確定：2026-11-10。** 原元データを使った GitHub Actions [#42734690690](https://github.com/zuizui0223/azami/actions/runs/42734690690) **SUCCESS**、artifact [13726691725](https://github.com/zuizui0223/azami/actions/runs/42734690690/artifacts/13726691725)、ZIP SHA-256 `575051561a2fcf70e4ee6e065ed60b71a671746f1c4cc60cbe753f2a11d5cbb5`。成果物 `v5_background_paired_overlap_summary.json` を独立してダウンロードし、ZIP全体のSHAと元のJSON・感度結果を検証した。未公開の元座標・写真・撮影者IDは成果物に含まれない。

## 1. 何を推定したか

- 気候：BIO01、BIO04、BIO12、BIO15、RSDS。標高なし。種ごとのWCVP在来／導入陸地を0.5°面積重みで抽出し、共通PCA2軸を構成。地域20°内で、同じ8セルの観測気候密度を**当該地域で利用可能な気候密度で補正**してSchoener Dを推定。
- 頭花：同じ写真由来の画像角度・CIELAB C*・画像輪郭指数。画像に関するPCA2軸に投影したD（**3形質のうち2つのPCA軸**を用いる。全3次元Dではない）。補助は輪郭なし角度＋C*の2形質D。
- 原V5と同じ17×8 / 11×7在来×移入地域、各8個の1°セルを32反復、同じ乱数と頭花コホート。Spearman ρを地域行・列ラベル置換4,999回で検定、**主結果3形質・h=0.5の2種をHolm補正**。
- 背景なしの従来の出現地点ベースの気候Dも、同じセルを使って再計算。これは背景補正した気候Dと**異なる推定対象**である。

## 5. 科学的な判定

**支持される（観察的・モデル依存）：** *C. arvense*で、地域ごとに利用可能な気候で補正した気候Dと、写真から測った3形質ベースの頭花Dが正に関連。1地域除外・KDE幅に対して符号は安定した。

**まだ強く主張できない：** (i) 角度と色のみでも同じ正相関があること、(ii) 他種への一般化、(iii) 気候変化が頭花形態を引き起こしたこと、(iv) 新規気候への遺伝的適応や収斂進化。(i) は画像回転依存の輪郭による測定アーティファクトを排除できないため、今回の最重要制限である。

**以前の結果との関係：** 従来の「気候Dと頭花Dは関連が検出されなかった」は出現地点ベースのDの話であり、今回の背景補正Dの陽性と矛盾しない。なお背景補正した地域間DはWCVPの地理的利用可能性定義と平滑化方法に依存し、客観的な因果気候効果ではない。

**論文での位置：** V5 Part IIは (1) 全分布域の気候占有D・新規気候の割合、(2) 同じ地域ペアの背景なし／背景補正Dと頭花D、(3) 新規気候と類似気候での頭花D、(4) 輪郭なし感度、の順に示す。*C. vulgare*の旧気候希少度は主張に戻さない。

## 6. この結果の次の必須検証

- まず頭花輪郭指数の回転不変な代替（実物の縦横比を称するのではなく、写真輪郭の長短軸比など）を独立監査し、**同一の地域と写真を保って**再計算する。新形質への変更後は事前の3形質Holm familyとは別の感度として報告する。
- 原頭花の測定精度・撮影角度の地域偏り、地域間の観測機会と系統／導入史を別途確認する。
- 結果を有意性だけで選ぶのを避ける。輪郭なしの非有意結果も本文またはSIで必ず並置する。
