# Ⅰ　気温と降水の季節性を含めた比較

年降水量、年平均気温、短波日射の3軸と、それらにBIO04、BIO15を加えた5軸を、同じ157,822適格写真、同じ分類群・セル・乱数抽出で比較。1°は63分類群7,117分類群セル、5°は31分類群814分類群セル。類似の基準は標準化軸当たりの二乗平均平方根を固定した（距離閾値0.9／1.162）。したがって類似判定と適格な分類群ペアは変わり得る。各24反復。標高なし。

| 尺度 | 分類群間の頭花距離減少 3軸 → 5軸（補正P） | 分類群内の減少 3軸 → 5軸（補正P） | 年降水→下向き角度 3軸 → 5軸（5軸の95%区間）|
|---|---|---|---|
|1°|.033 (.016) → .031 (.076)|.075 (.004) → .084 (.004)|.160 → .117 [.015,.220]|
|5°|.050 (.016) → .065 (.012)|.164 (.004) → .238 (.004)|.170 → .183 [.022,.339]|

距離減少は置換期待を超える標準化距離減少。補正は各仕様・検定内の2粒度に対するHolm。方向は異なる分類群の地点対のうち分類群ペア平均差を取り除いた全組合せの標準化係数。95%区間は分類群ブートストラップの点別区間で、季節性追加による係数差自体の検定ではない。系統の独立性や地理的自己相関を解消しない。

### 日射と彩度C*

分類群ペア平均の標準化係数は1°で−.558から−.450［−.817,−.033］、5°で−.724から−.448［−1.076,+.385］。分類群ペアの平均差を除いた地点差では1°で−.059から−.091［−.242,+.017］、5°で+.007から−.123［−.313,+.071］。区間は季節性を含むモデルの点別95%区間。各分類群ペアの平均差は広域の分類群分布と頭花の対応で、個体や同一集団の応答を追跡した量ではない。

### 共線性

符号付き地点差回帰の重み付き設計行列から計算。各地点対の順序を両向きにしたときの相関行列を用い、VIFは逆行列の対角成分。全地点対で最大VIFは1°の分類群平均差1.36、地点差1.66、5°でそれぞれ1.93、2.20。最大の絶対相関は5°地点差の年平均気温と気温季節性（−.66）。降水季節性のVIFは1.12–1.59、日射は1.11–1.73。季節性係数を含む設計で強い線形従属は見られなかった。これは説明変数間の診断で、地理や分布史との交絡の診断ではない。[再計算](https://github.com/zuizui0223/azami/actions/runs/42602320650)
