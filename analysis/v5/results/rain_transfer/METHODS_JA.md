# 在来域から移入先へ　雨と頭花角度の予測転用

## 対象と予測の順序

前段で確認した生態仮説は、花粉への雨の損傷が大きい場所ほど、頭花がより下向きに咲くというもの。比較は C. arvense と C. vulgare の各種内で独立に行う。今回の目的は現地適応の検出そのものではなく、予測方向の表現型変化があるか、その予測を異なる地域に持ち出せるかを調べること。在来域で地域外予測が成立しない場合、移入域で予測とずれても移入後の形質変化を同定できない。

1. 使用可能な元写真で測定された重力未校正の画像角度（0–180°）を用いる。観察者×粗い地域セルの重複調整は全域の気候ニッチ解析と共通。S2の地域セル（経度5°×等sin緯度帯）を20°空間ブロックとの交点で区切る。各単位の算術平均に等重み。新規と類似が同じセルに共存する場合は別単位となる。
2. 在来域のみで、セル平均角度を暖季降水BIO18、最暖月最高気温BIO05、日射RSDSに線形回帰。標高は欠測判定も含めて用いない。減雨時の上向き化・増雨時の下向き化を表す期待符号は降水の正。測っているのは個体の変化ではなく、占有地点間の表現型差。
3. 在来域で20°ブロックを分離した5分割検証。未使用セルの予測誤差を、各訓練部分の在来域平均角度を使った誤差と比べる。Q²>0で平均より改善、Q²<0で平均より悪い。全在来域で学習した同じ式を、移入域内の在来類似気候、次いで新規気候の全測定対象に適用。各群でQ²、予測平均と実測平均、差、RMSEを記録。移入先での基準は学習した全在来域の平均角度。全域における在来類似／新規判定は、温度・降水の平均／季節性と日射による背景補正PCA上の在来95%密度領域を用い、既報の重複D・領域外割合を照合する。
4. 方向性も直接評価する。移入セルごとに、在来域の角度観測があるセルのうち、BIO01・BIO04・BIO12・BIO15・RSDSを在来セルのSDで揃えたユークリッド距離で近い5セルを取り、その平均と比較。頭花角度とBIO18はマッチング軸に含めない（年降水と季節性は含む）。移入−在来のBIO18差（mm/月）が正ならwetter、負ならdrier。角度も同じ順序で引く。湿潤側で角度差が正か、降水差に対する角度差の傾きが正かを確認する。ここでの比較対象は生態的な参照地点であり、移入元の遺伝的由来を同定した集団ではない。
5. 移入先の誤差・ずれの区間は、在来および当該移入群の20°ブロックを別々に復元抽出する999回のbootstrap。モデルを再学習し、再抽出した在来参照集合から最近傍も選び直す。同じブロックの重複抽出に伴い参照にも同一セルの重複を許す。区間は平均的な差の点別区間。個々のセルの予測区間や多重補正済みの新規仮説検定ではない。新規性の分類・気候ラスターそのものの不確実性は含まない。ワークフロー外に写真ID、座標、観察者IDを出力しない。
6. 最暖四半期が各写真の開花月に一致するか、撮影時の降雨、花粉生存・種子生産、移入元の遺伝子型は測定していない。地域差には種内の遺伝構造、可塑性、観察時期、撮影条件の影響が入りうる。
