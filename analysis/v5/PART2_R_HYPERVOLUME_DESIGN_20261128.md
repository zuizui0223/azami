# Part 2: standard Gaussian hypervolume pilot (2026-11-28)

The previous 40^3 trait/5D climate histogram-HDR computations are grid-based approximations. This separate exploratory sensitivity fits **R hypervolume::hypervolume_gaussian** to actual cell medians; **hypervolume_set** provides intersection/union/unique components. References: Blonder et al. 2014 doi:10.1111/geb.12146; Blonder et al. 2018 doi:10.1111/2041-210X.12865. Document the installed version in sessionInfo.

- Three traits: image-referenced angle, CIELAB chroma, projected outline ratio. Freeze the earlier 1-degree complete-record cell-median cohort and species-specific native mean/population SD. Use full native versus all introduced; full native versus primary novel-climate cells; geographic matched analogous versus novel for both frozen climate classifications (30/183 and 146/316 pairs). Verify cohort and regional balance before fitting.
- Common bandwidth 0.5 native SD, 95% probability content, sd.count=3; target 60,000 stochastic points before thresholding and set max 12,000. Repeat same data at twice target / 20,000 set max with independent seed. Sensitivities h=.35/.75, 90/99% content, angle/chroma only. Native/range contrasts also include eight fixed equal-cell-number draws; matched arms already have equal n. Equal-n draws are not regional matching of native and introduced, nor confidence intervals.
- Five-dimensional climate package pilot uses observed climates of the identical complete-trait cells, standardized on native cell climate scales, equally weighted per cell. **Raw occupied climate support only**; it is not background-corrected climatic occupancy. Target 100,000 points, double resolution, equal-n sensitivity. Preserve earlier background-corrected PCA-env and 5D grid analysis as separate evidence. A continuous background-corrected ratio of occurrence/availability density requires a separate estimator; do not conflate raw package volumes with corrected occupancy.
- Report all 108 comparisons, numerical resolution and sample counts. Set-overlap geometry is approximate and sensitive to Monte Carlo point density. No new P-value search, no inference of species differences, selection, novelty of alleles or equal volumes. Existing region-block null tests and near-neighbour novelty analysis remain separate. The percentage of novel climate cells inside a calibrated native phenotype reference is not a geometric overlap fraction.
- Export only synthetic points from fitted volumes (reference-only, intersection, comparison-only; capped at 4,000 per component) and aggregate tables; no observed points, coordinates, raw fitted object/Data slots, IDs, or private intermediate CSV in artifacts. Keep existing poster and manuscript unchanged pending actual results, numerical convergence and provenance checks.
