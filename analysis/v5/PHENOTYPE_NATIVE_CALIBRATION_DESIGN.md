# Native-reference support calibration (exploratory)
Existing extrema comparisons favor the much larger native sample. Use geographically disjoint native reference/calibration blocks: 32 randomized block splits with 256 reference cells and 128 held-out calibration cells, equal native sample sizes in both species, no overlap of native geographic blocks within a split. Evaluate all introduced matched cells against the same reference in each split. Mean distance to five nearest reference phenotype cells, standardized on reference cells only. Normalize distances by the held-out native 95th percentile; calculate exceedance of native held-out 90th/95th/99th percentiles. Average across splits for each introduced cell, not as independent replicates. Primary trait space angle+chroma; three-trait (image outline) sensitivity. Both original climate definitions; no relabeling by phenotype. Two-sided whole paired-block swaps, exact where feasible; Holm across all 32 contrasts. Report pointwise paired-block intervals conditional on native-reference draws, and leave-one-block-out. The calibration baseline is the observed held-out native score distribution, not a test of genetic novelty or strict equivalence. Sparse/unmeasured native phenotypes, image artifacts, ancestry, temporal changes remain unresolved. No per-cell output. This is a distinct diagnostic, not an attempt to replace failed omnibus significance.
