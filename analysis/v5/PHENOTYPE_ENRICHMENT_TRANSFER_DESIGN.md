# 固定した種内濃縮曲線の地域外再現性
2026-11-26。結果3の3形質・方向性/非線形濃縮解析は既に完了。主仕様のC. vulgare彩度一次項・二次項、向き二次項に未補正P<.05の候補があるが、Holm補正後は非有意、感度では弱い。今回の追加は同じモデルの地域依存性の監査であり、別の仮説・モデル・気候変数を探索しない。結果2の種間係数、時間軸、明度は使わない。

- 全125在来観測済み組合せ、固定五分位、等セル重み、固定気候区分と地域マッチを再現する。24元係数を1e-6以内で再現しなければ中止。
- 1地域ずつ除外して、元の6項モデルを他の地域だけで推定。全係数の符号安定性、最小最大、最高/最低または両端/中間の濃縮比の範囲を報告。除外地域は独立な導入事例ではない。全地域に共通の祖先・導入史・観測誤差を除いたことにはならない。符号安定性を新しいP値と扱わない。
- 同じ除外モデルで未使用地域の濃縮識別を評価。ペアの合計分布(a+b)と既知の1:1群重みを条件に、ペア切片のみプロファイル。形質係数は学習地域から固定。これは条件付きのラベル識別・相対密度比の移植で、気候から形質を予測するモデルでも未知地点の生息適性でもない。無濃縮モデルの損失2N log2からの減少率をセル対重み/地域等重みで出す。単一地域への依存、負の汎化能力もそのまま報告。
- 元の全6項に加え、同じ枠組みで一次3項のみ、彩度2項除外、向き2項除外を固定診断として比較。どれか一つを有利なモデルとして後付け採用しない。全6項との差は方向性・非線形・個別形質の寄与に関する地域外識別の増分。追加検定を行わずPの探索はしない。全折りが成功した仕様のみ集計、欠落折りを選択的に除外しない。
- 結果が正でも適応度・選択勾配・遺伝子・進化速度を測ったことにはならない。非独立な地理反復での再現性評価であり、自然選択の直接検証には個体の生存/繁殖・遺伝性等が必要。主結果の未補正Pと既存補正、全体検定の不一致を維持。新しい仕様を追加して有意性を探さない。集計のみ出力。mainとポスター未変更。
