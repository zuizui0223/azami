# Temporal feasibility gate: before trait-effect inference
Use all 297,622 original wild source records before cross-year observer thinning. Fixed 2011–2015, 2016–2020, 2021–2025 windows (exclude incomplete 2026). The primary comparison is 2016–2020 versus 2021–2025 in 0.25-degree cell×calendar-month strata, with >=3 eligible records, >=3 distinct observers and >=2 years in each period. Deduplicate one observer per local cell×year×month first, outcome-blind. Sensitivity: 0.1 and 1 degree, 2011–2015 versus 2021–2025, >=5 records. Use archive's source and eight endpoint usable-head gates. Native and introduced, analogous and novel climates, mixed separately. Climate assignments use frozen original V5 native contour (validate exact D; classify original observations in annual climate space; fixed over time). Within each spatial/month stratum a single climate class based on all source observations, not traits. Minimum 30 local cells and 8 broad geographic blocks per planned group to proceed to exploratory temporal modeling; this is a feasibility heuristic, not power or genetic validation. Dates are observation dates; these are local sampling units, not identified populations or dated introduction events. Sampling changes within the same cell remain possible. No phenotype values, effect estimates, location/observer IDs or per-cell results exported. If inadequate support, do not weaken gates by outcome. Historical records and common gardens remain necessary for SGV/rapid adaptation.
