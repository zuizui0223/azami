# 原S1の写真形質の分散：RFの負の外挿Skillを解釈するためのQC診断

**ステータス（2026-10-31）：実行コード・匿名集計仕様を定義。元S1の実測結果は保護Actionsで確認するまで未確定。** 既存GEB本文、S1 80検定・S2 128検定・H3c、これまでのRF結果を改変しない。

## なぜ実行するか

28変数から土壌6変数を追加した34変数RFで、元S1の頭花向きの未知分類群Skillは−0.05646→−0.05677、未知地域Skillは−0.00978→−0.06021と改善しなかった（[source-real run #41198399573](https://github.com/zuizui0223/azami/actions/runs/41198399573)）。これは**環境と形態が無関係**という検定ではない。写真単位のばらつきが、分類群内の場所間変動をどの程度上回るかは別途調べる必要がある。

## 計算方法（単一の登録済みQC仕様）

- 検証済み**313,350元S1観測**の暗号化ソースを保護環境内のみでSHA256/AES-GCM復元、元のphysical climate decoderでソースレシートを生成。追加外部ラスタ取得は不要。
- 登録済み8画像構成形質（angle、lightness、chroma、joint hue sin/cos、aspect、circularity、solidity、width_profile）、**1°と5°**を独立集計。各構成形質の`__eligible`判定と数値QC、最低**3写真/分類群×地理セル・8セルと40写真/分類群**を厳格に適用。
- 各セルの写真形質**中央値**を元のRFと揃えて取得。1つの分類群につき、①セルの写真中央値から写真ごとの平均二乗偏差の平方根（within-cell写真散布RMSE）、②各セル中央値とその分類群のセル中央値中心との差の平方根（among-cell空間散布RMSE）を計算する。セルは等重み、分類群ごとの散布とその**among/within比**の5/50/95分位点だけを公開。
- 色相は生の0–360°数値差ではなく、単位sin/cosベクトル間の**円周弦距離**で一貫して比較する。元のRF同様、セルsin/cos中央値のノルムが0.2未満となる不安定なセルは除外し、分類群の支持数を再判定。
- 匿名集計での問いは、**同一分類群内のセル間写真形質変動が、セル内の写真間変動より十分大きいか**。強いセル内散布があっても、写真撮影誤差と真の個体差・季節差を同定できない。比はICCでも撮影精度の推定値でもない。

## 重要な推定対象の違い

**これは元S1の写真形質QC対象全体についての診断であり、28変数/34変数の環境完全ケースに限定したデータではない。** そのため、この診断とRFのSkill/対象分類群数を直接比較して効果を定量してはいけない。また、この結果は環境変数の寄与や因果関係の推定ではない。

元観測ID、分類群識別子、撮影者、座標、個別写真形質・セル中央値、RF予測、空間的な細分類結果は**保存・公開しない**。公開は元S1 SHA、1°/5°ごとの分類群数・セル数・写真枚数と分散比の集計値だけ。解析を完了できなくても、凍結原稿の肯定結果は変更しない。
