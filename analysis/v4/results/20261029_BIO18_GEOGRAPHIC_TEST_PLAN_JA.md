# V4.1 BIO18 × 頭花画像角度：地域ごとの再現か、分類群構成の効果か

**主目標：** 全球のアザミ属の「多雨地域ほど画像上の頭花が下向き寄り」という分類群間の関連が、**特定の地域の形質・気候組成**によって見かけ上生じているのか、地域構成を調整しても方向が残るのかを原S1写真の実データで評価する。弱い画像形質間相関（r≈−0.2）を生態学的機構として押し出すのではなく、GEBの主結果の**一般性と反証可能性**を高める。

## 実際に分かっていること

- 凍結したS1のBIO18 + BIO05 + RSDS + 標高4変数モデル：168,907件/178分類群、分類群間標準化β **+0.045447**、Holm P **0.00920635**（80検定中1件）。
- 先行する別仕様のS1 BIO12 + BIO1 + BIO4 + BIO15 + RSDS 5変数モデルでは、237/191/143分類キーを用いた全球の年降水量の正の分類群間関連が、球面二次地理項を調整すると**6/6仕様すべてで95%区間がゼロを跨いだ**（[元の結果](20261022_S1_RAIN_SPATIAL_GEOGRAPHY_RESULT_JA.md)）。東経60°–180°帯の種群が重要だった。
- **BIO12とBIO18、元の5変数と凍結4変数、元の分類群母集団は同一ではない。** 既存BIO12の空間感度を「BIO18も消える」と転記してはならない。

## 新しい解析の設計（探索的・結果を見る前に固定）

1. SHA256 `342d78e9a8a960e8d9bdcf0bc2cdacd13bee48214a8b962419d5a71d5aef46ed` の暗号化保存された原S1デコード表を、GitHub Actions上でのみ復元。313,350元在来観測、元5気候＋画像角度170,066適格観測/244分類キーを照合する。
2. CHELSA 1981–2010 **BIO18・BIO05** とWorldClim標高を**原位置の元ラスター画素**から新たに抽出。原CHELSA RSDSを併せ、**BIO18 + BIO05 + RSDS + 標高**の4説明変数を維持する。これは旧凍結解析の**全12気候完全例の168,907件**と母集団が完全一致するわけではないため、結果のnを必ず別記し、凍結Holm結果を上書きしない。
3. 分類群ごとに①写真数による平均と②同一分類群内5°緯度経度セルの等重み平均を並行。学名衝突キー・5枚未満の分類群を除く。分類群間のOLSにHC3点別95%区間を用いる。BIO18の係数は**100 mm/月当たりの画像角度（度）**。
4. 地理調整前、元の3経度帯撮影構成比調整、固定の球面二次8項調整を並べる。さらに**主要撮影経度帯を一つずつ除外**して符号・大きさ・CIを確認し、各帯内の同じ4変数モデルも探索的に算出する。経度帯は大陸・系統・独立進化イベントの代理ではない。
5. 結果は**元ID・座標・写真・撮影者情報を一切公開せず**分類群数と係数・区間のみ保存。複数モデルの探索的CIはHolm調整を追加していない。大きなnの写真を独立した「分類群反復」と数えない。

## 判定規則：どうなっても生態学的意味がある

- **H1（地域を越えた勾配の候補）:** BIO18係数が球面空間調整・セル均等化・複数地域留置のどれでも正で、データ支持域と分類群数が十分なら「同じ向きの関連が広く現れる候補」としてGEB本文を強める。ただし系統独立な収斂・雨よけ適応の証明にはしない。
- **H2（地域・放散の組成が作る全球勾配）:** 全球の正の係数が地理調整・特定の帯の除外で大幅に縮小する場合、全球の形態―気候対応は地域ごとの種群構成に依存する。その結果こそ**「共通気候則か、放散史で組み立てられた形質地理か」**の生物地理学的成果となる。
- **未識別:** 元気候・画像角度の撮影系、系統不均一性、空間自己相関、分類群平均の偏りのいずれかが解決できない場合、全球一般化を主張しない。

**原稿への反映条件：** 実データの集計JSONが生成され出所とn・係数を検証できた後だけ。実測前はこの試験設計を新しい陽性発見としてResultsや要旨へ挿入しない。現行V4の元Holm統計4件と28ペアSIは凍結したまま。
