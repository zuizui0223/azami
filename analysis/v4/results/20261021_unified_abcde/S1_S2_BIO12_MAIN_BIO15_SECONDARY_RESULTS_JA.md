# 年降水BIO12を主検定、降水季節性BIO15を補助検証に固定したS1–S2連結解析（2026-10-21）

**結論：** S1全球自生域では、種間の年降水量BIO12に対して画像上の頭花角度が大きくなる関連が支持された。一方、降水季節性BIO15は**種間係数が正方向の点推定でも95%区間がゼロを含み、有意な独立効果とは判断できない**。今回のS2実行では、*Cirsium arvense*・*C. vulgare* の在来気候範囲外の**多雨地点と頭花角度を、同じ元写真から直接検証**したが、十分な独立セルが残る北米のいずれも**明瞭な多雨→下向き化は支持されなかった**。

**原データの再実行**：[GitHub Actions #39559452415](https://github.com/zuizui0223/azami/actions/runs/39559452415) success。元665,115観察の分類・WCVP自生／導入状態と歴史的同一画像計測法による向き適格**173,737観察**。元投稿者×分類群×5°セルごと1観察・有効観察日を要件とすると**94,060観察**。1981–2010年CHELSA v2.1元原本BIO12・BIO15をSHA256で再認証し、すべての元写真座標の**元画素を取得**。原本TIFFは処理後廃棄し、撮影者・観察ID・正確な緯度経度はprivate runnerから出していない。元結果 `S2_introduced_rain_seasonality_vs_original_head_image_angle.json` SHA256 `084b28ec90c20bf08826fca412e4b4f685257334affc3dcd14f20899f66ee0f7`、artifact `12326369656`。[固定数値レシート](S2_BIO12_PRIMARY_BIO15_SECONDARY_VERIFIED_20261021.json)。

## S2年降水主検定：導入先の極端な多雨地点は下向き化しているか

**在来域でのBIO12 95パーセンタイルを、向きの実測値を見ずに地域セル等重みで固定**。新しく導入された各大陸内で、元の在来域の95%より雨量の多い地点とそれ以外の地点の頭花画像角度を比較した。併せて導入域のBIO12上位1/3・下位1/3を**向きを見ずに**分類。角度0°は画像上向き、90°水平、180°画像下向き。撮影者の視点を補正した重力傾斜ではない。

**最も比較可能性の高い北米**：

|---|---:|---:|
| 在来BIO12 95%基準 | 1,690 mm | 1,734 mm |
| それより多雨な元画像観察／独立5°セル | **576／21** | **809／19** |

「効果0」を証明したわけではない。セルの独立性・撮影姿勢・本当に同じ生物個体の繰り返しか・開花段階・経年的な遺伝的変化は検証されていない。*vulgare* の極端多雨地点の負の点推定−9.60°も**区間が0を含み、雨よけ機能が逆転したという進化的結論にはならない**。

BIO12は**主解析のまま保持**し、上表のセル不足から肯定・否定の有意な判定を作らない。写真を多く持っていても独立した地理セル数が少なければ「個体の迅速な反応」だと解釈できない。

## 次の判断と研究主張の境界

1. **主張できること：** S1の全球種間の向き×年降水に正の観測的関連がある。S2では、同じ種が導入地で占有する気候条件は変わっていても、**多雨な新環境で写真上の頭花角度が一律に増大するという強い予測は現データで確証されていない**。
2. **主張できないこと：** 画像の角度は重力基準でなく、写真の姿勢・花期・頭花切出しの不確実性がある。高BIO12地点の角度差が小さいことを「形態進化は固定」「短期可塑性なし」「雨よけ仮説が否定された」と読むことは不適切。
3. **次の必要対照：** 同じ頭花の標準重力基準の角度反復と、元撮影者×地域の視点・花期の感度。野外で実際に降雨を受けた生殖器官の被濡れ・花粉／蜜・稔性は別の実験。
4. **論文の主線：** S1年降水×頭花提示角は自生域空間の仮説、S2は人為導入による異なる雨環境下での形態応答を検証した観察研究。S2の結果だけで進化の速さ・T2の遷移年代・T3の収斂数を示したと書かない。
