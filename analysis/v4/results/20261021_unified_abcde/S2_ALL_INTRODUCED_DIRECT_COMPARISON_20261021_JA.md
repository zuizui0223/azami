# S2 主解析：在来域 vs 全導入域（北米限定を撤回）

**2026-10-21 / ユーザー指定の単純比較。既存の実データ解析の主結果を再配置。** *Cirsium arvense* と *C. vulgare* それぞれについて、WCVP/TDWGが明示的に導入域と判定した**全導入地域**（北米以外も含む）を在来域全体と比較する。十分な写真のある北米だけに限定しない。**「全導入域で多雨」＝すべての観察地点が多雨ということではなく、全導入域における観察地点の年降水量中央値が在来域より高い**という意味。

## 結論

**肯定結果：** 両種とも全導入域では自生域よりも年降水量の高い観察地点に偏っている。これは全球の全導入域を使った、実際の出現記録上の共通パターンである。

**形質の結果：** 画像上の頭花角度中央値は両種とも概ね同じ（1°刻みで約1°小さい）。90°以上の画像角度の割合も2種で共通して増えておらず、セル再標本化区間は0を含む。**より湿潤な導入域への占有の変化と、頭花の下向き角の一様な増大は対応しない**という記述的観察は可能だが、「向きは進化的に固定」「可塑性がない」「雨よけ適応が否定された」とは結論しない。

**比較上の限界：** 年降水中央値は形質選別前の出現記録を用い、角度の分布は同じ元ソースから写真測定可能な観察を抽出している。両方とも元撮影者×5°セル制限／地域セル重みを使うが、同じ個体を導入前後に撮ったわけではない。頭花画像角度はEXIF正立補正後のカメラ縦軸基準（0°画像上、90°水平、180°画像下）で、真の重力傾斜ではない。1°ビンの中央値は連続未丸めの平均角度ではない。地域全体の気温・日射・雨季・観察努力・撮影者の違いを原因分離したものではない。
