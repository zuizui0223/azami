# S2：導入域の湿潤側占有と頭花画像角度の分布はどう接続するか

**2026-10-21・実行済み探索解析。PR #144、GitHub Actions [#39582985273](https://github.com/zuizui0223/azami/actions/runs/39582985273) 成功。** 実数値は run artifact `12338801038` 中の `S2_rain_niche_phenotype_decomposition.json`。元画像・暗号化元観察・元撮影者・元CHELSA TIFFをバイト同一性とプライバシー制約付きで再結合。以前の固定V3/GEBの解析と主張は変更していない。

## 科学的な問い

「両種とも導入先では雨量が多い」に続けて、同じ植物種の頭花の向きも湿潤ニッチの再配分と整合して変わるのかを確かめる。自生域と導入域の**平均角度同士を比べるだけではない**。各種の自生域で決めた雨量分位点 q25/q50/q75/q90/q95 を全地域で固定し、(a)利用可能な雨量帯、(b)記録された雨量帯の占有、(c)同じ帯における頭花角度分布を区別する。

原ソース２種合計 **297,622** 野外観察 → 形質非選別の元撮影者×5°セル一意化 **144,178** 観察。元画像角度適格は **173,737**、日付/撮影者×セル一意の角度コホートは **94,060**。背景気候はWCVP／TDWGの0.5°面積重み付き領域、5元解像度 CHELSA v2.1を用いる。画像角度はEXIF縦軸基準、重力角ではない。

## 1. 両種とも占有する「湿潤側25%」が増えた

| 自生域で定義したq75を超すBIO12帯 | *C. arvense* | *C. vulgare* |
|---|---:|---:|
| 元自生域での観察比率（セル等重み） | 25.03% | 25.04% |
| 元導入域での観察比率（セル等重み） | **49.85%** | **56.57%** |
| **観測占有の変化** | **+24.83 pp** | **+31.54 pp** |
| WCVP利用可能域内の背景面積：自生→導入 | 20.80→29.60% | 10.82→39.47% |
| **利用可能背景面積の変化** | **+8.80 pp** | **+28.65 pp** |
| 占有変化 − 背景変化（記述差の差） | **+16.03 pp** | **+2.89 pp** |

**重要な比較：** *arvense* では観測上の湿潤側への再配分（+24.8 pp）がWCVP背景で湿潤気候の面積が増えた分（+8.8 pp）より大きい。一方、*vulgare* では湿潤気候の背景面積も大幅に増えており（+28.6 pp）、出現割合の増加（+31.5 pp）の大きな部分は背景の違いと併存している。この差は有益な**機会分布 vs 記録分布の対照**であるが、WCVP領域は真の侵入可能生育地・独立植物集団・観察努力を直接表さない。**選択・適応・湿潤環境選好の原因としては認定しない。**

さらにq95より上の帯では、*arvense* の出現割合は5.00→6.82%、*vulgare* は5.11→10.46%。両種の中央値が湿潤方向へ動いたことは、ただちに「従来の雨量限界を突破した頻度が高い」とは同義ではない。

## 2. そのうえで頭花の向きを降水帯別に調べる

全６雨量帯を観察する共通サンプルに対し、画像角度を1°の経験確率分布にし、各帯の確率分布をソース観察の雨量帯占有比率で重み付けした。求めたのは**CDF/分布全体の記述的再標準化**であり、回帰直線１本や地域平均角度ではない。

- **F_native**：自生域の雨量帯占有割合 × 各帯の自生域画像角度分布
- **F_climate-reweighted**：導入域の雨量帯占有割合 × 各帯の自生域画像角度分布。**降水帯の占有のみ**を替えた場合の算術的参照
- **F_introduced**：導入域の雨量帯占有割合 × 各帯の導入域画像角度分布

恒等式 `F_introduced - F_native = (F_climate-reweighted - F_native) + (F_introduced - F_climate-reweighted)` を角度閾値ごとに保持。

| 画像上の角度≥90°の割合、導入域−自生域 | *C. arvense* | *C. vulgare* |
|---|---:|---:|
| 自生域 | 35.07% | 25.38% |
| 導入域 | 31.24% | 25.92% |
| 観測差 | **−3.82 pp** | **+0.54 pp** |
| 雨量帯占有割合に対応する算術的部分 | −0.61 pp | +0.87 pp |
| 同じ雨量帯内の角度分布差に対応する算術的部分 | −3.22 pp | −0.34 pp |
| **観測差の199回空間セル再標本化区間** | −8.90〜+0.36 pp | −3.59〜+4.46 pp |

分布全体の1D Wasserstein W1は *arvense* **2.97画像度**、*vulgare* **1.30画像度**。1°への離散化とサンプルのセル重みがあるため、他のレポートの連続角度のW1と無条件に同列比較しない。**いずれの観測差の区間も0を含む。** ゆえに「湿潤な導入域に進んでも、頭花は遺伝的に固定されていた」等はまだ言えない。

## 3. どこまでが実証された知見か

**支持された記述的パターン：** 同じ２種で、導入域は湿潤側の降水帯への出現集中を示す。一方、下向き寄りの画像角度がどちらの種でも一様に増えたという形質分布のパターンは現在確認されていない。

**未識別：** 背景分布差と観測努力・導入史を分離した因果効果、他の4気候（BIO1/BIO4/BIO15/RSDS）を厳密に一致させた「降水固有」の条件付き画像角度差、カメラ姿勢と同じ頭花の誤差、自然選択・可塑性・適応速度。199回再標本化は5°地理セルを元ソースと角度標本で同時に抽出した**探索的な感度区間**で、独立遺伝個体群の厳密CIではない。

**次の主解析：** この６雨量帯と利用可能背景を保持しつつ、各帯の撮影選択・他気候因子・撮影月を監査する。雨量帯内で環境の共通支持がある部分だけ、条件付き角度CDF/分位点とその地理的頑健性を検証する。雨と画像角度のデータを見て閾値や採用種を再選択しない。

**実装：** `analysis/v4/native_rain_niche_trait_redistribution.py`、[元TIFFの同一ワークフロー](https://github.com/zuizui0223/azami/blob/codex/v4-native-integration-workflow/.github/workflows/v4-native-pca-env-full-background.yml)、`tests/test_v4_native_rain_niche_trait_redistribution.py`。上記の実数値は成功済みの#39582985273のソースを使用。後続版の背景シフト比較の集計は同一数学的定義で補強中。
