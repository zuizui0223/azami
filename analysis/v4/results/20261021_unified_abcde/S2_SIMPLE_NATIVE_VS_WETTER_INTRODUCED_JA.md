# S2｜在来域と、より多雨な北米導入域の直接比較

**2026-10-21 / 既存の実測値を再整理（新しい統計解析ではない）。** 最初の問いを「同じアザミ種が、在来域より湿潤な地域へ導入されたとき、頭花の画像上の向きは異なるか」に戻す。解析条件を増やさず、北米導入域（2種とも観察数・独立空間セルが多い）を同じ2種の在来域と比較する。降水量・角度は別コホートの原データ集計であり、同一個体の導入前後の時間差を意味しない。

## 主図相当：一つの比較、一つの表

| 指標 | *Cirsium arvense* 在来 → 北米導入 | *Cirsium vulgare* 在来 → 北米導入 |
|---|---:|---:|
| 年降水量 BIO12 中央値 (mm) | **658.6 → 832.0** | **666.0 → 904.0** |
| **北米導入−在来の年降水量中央値差** | **+173.4 mm** | **+238.0 mm** |
| 頭花画像角度の地域セル等重み平均 (°) | **72.604 → 72.163** | **66.612 → 66.265** |
| **北米導入−在来の画像角度差** | **−0.441°** | **−0.347°** |
| 角度差の地域セルbootstrap探索的95%区間 | **−4.955 ～ +4.362°** | **−4.891 ～ +4.228°** |
| 原画像角度・撮影者×5°セル均等化の観察 (在来 / 北米) | 21,870 / 25,052 | 16,246 / 25,447 |
| 角度に使った独立5°セル (在来 / 北米) | 186 / 80 | 124 / 84 |

降水量の中央値は**頭花角度の計測可否で選別していない野外観察**からの各種の自生域中央値と北米導入域中央値。元CHELSA 1981–2010、元TDWG/WCVP分類、元撮影者×5°セル制限を使用。頭花角度は別の**写真測定可能な観察コホート**。**0°＝画像上向き、90°＝水平、180°＝画像下向き**で、実際の重力基準の頭花傾斜ではない。

**支持された結果：** 両種とも、北米の導入域は自生域より観察された年降水量の中央値が高い。両種とも、画像上の頭花角度の地域平均との差は小さく、bootstrap区間は0を含む。この比較では**多雨環境への分布移動に対応した一貫した下向き角の増大は検出されない**。非有意＝0差の証明ではない。

**言えないこと：** 移入によって同一集団が進化したか、移入後の可塑性がないか、写真の方向が頭花の真の重力方向か、頭花が実際に雨を遮断しているか。新しい地域は「多雨になった時系列」ではなく、在来域より雨が多い**別の地理環境**。在来域全体と北米導入域は、気温・光・季節・観察者等が異なる可能性があり、雨の単独因果効果ではない。

## S2の研究主線を簡潔化

1. **環境：** 各種の在来域と北米導入域で、年降水量中央値を比較（上表）。
2. **頭花：** 同じ2地域における元写真の画像角度の平均・5°地域セルbootstrapを比較（上表）。S1の種間では正方向という結果とのスケールの違いを記述する。
3. **妥当性監査：** 写真品質区分・観察月・撮影者集中・カメラ向きの相違を後続の限定的な検査とする。残りの湿潤端Q90・W1・5気候マッチング・4雨量帯の解析は削除せず**補助・感度資料**に移す。
