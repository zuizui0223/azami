## 問いを変えずに二つの混合要因を点検

**主比較は変更しない：*Cirsium arvense* と *C. vulgare* それぞれの「在来域 vs 全導入域」。** 幅・Q10・Q90・下向き閾値等の形質主指標はここで新しく選定しない。完全なBIO12年降水量ECDF、完全な画像角度ECDF、同一観察のBIO12×画像角度 joint histogram を使う。今回の比較は**生物学的効果の推定ではなく、標本構成の診断**である。

### A：元野外出現の降水分布 vs 画像角度を測れた観察の降水分布

各種×在来/全導入域ごとに、**形質非選別の元WCVP野外出現**と、**同じ元ソース中の元画像角度適格かつ観察日・撮影者×5°セルを制限した標本**で、元CHELSA BIO12の全累積分布を重ねた。元の形質非選別出現と元画像角度適格集合は異なるため、この比較で技術的な抽出偏りを観察する。

| 対象種 | 在来：元出現/画像角度標本 | 全導入：元出現/画像角度標本 | 全ECDFの観察 |
|---|---:|---:|---|
| *C. arvense* | 30,523 / 21,870 | 38,406 / 25,657 | 各地域内の二本はおおむね近く、完全一致はしない |
| *C. vulgare* | 26,161 / 16,246 | 49,088 / 30,287 | 同様におおむね近く、完全一致はしない |

結果：**「導入域が多雨な環境を占有する」という主張は、写真測定可能な観察だけの特異な降水帯選択に単純には還元されない。** ただし残差の写真適格偏り、観察努力、地理セル内選別はあり、全標本の母集団代表性を保証しない。元出現集合を独立の実生植物サンプリングや真の個体数に読み替えない。

### B：全球導入域を地域別の全画像角度分布へ厳密分解

全導入域の元撮影者×5°セル等重みを**地域分割前に固定**した。TDWG1導入大陸ごとの**角度全CDF**は、元の共同BIO12×角度ヒストグラムを角度方向へ集計したもの。低支持の大陸を削除せず、合計すれば**全導入域の全画像角度分布が数値的に厳密再現**する。

| 写真群／地域別構成 | *C. arvense* | *C. vulgare* |
|---|---|---|
| 北米 | 25,052観察 / 80セル / **80.0%空間重み** | 25,447観察 / 84セル / **53.5%** |
| オーストララシア | 566観察 / 12セル / **12.0%** | 1,932観察 / 28セル / **17.8%** |
| アフリカ | 個別表示条件未達 | 1,187観察 / 20セル / **12.7%** |
| 南米 | 個別表示条件未達 | 1,622観察 / 16セル / **10.2%** |
| 東アジア等その他 | 39観察 / 8セル / **8.0%**（低支持を一括） | 99観察（うちtemperate Asia 35/7セル） / **5.8%**（一部低支持） |

**分布の形で見ると**、*arvense* では北米・オーストララシアの画像角度CDFは全球導入域に比較的近い一方、低支持の39観察／8セルの画像角度CDFは明確に異なる。この群の重みを外して再標準化した場合、**全導入域CDFは最大約1.44百分率ポイント変わる**（曲線全体の診断上の最大乖離；特定の角度を選んだ検定ではない）。これは全球導入域を主解析から排除する理由ではなく、**画像角度の小さな見かけ差が少数の地理セルと撮影構図に敏感**という警告になる。

*vulgare* では、北米・アフリカ・オーストララシア・南米の角度CDFは大まかに重なっている。ただしtemperate Asiaは**35観察/7セルで4.5%空間重み**を持ち、CDFの形が他地域と違う。2セル/64観察の低支持その他は全域の1.3%空間重み。これらを有意な地域分化や独立進化反復としない。

**補足数値の根拠：** 地域セル等重みで全導入域角度ヒストグラムを地域別の元ヒストグラムへ正確に分解してから、元の同じ幅（5画像度）で累積和を計算した。「低支持除外」曲線は**結果解釈の感度表示のみ**、全球主コホートは変えない。境界を跨ぐ地域の5°セルでも**元の全球セル重みは維持**。元の入力ヒストグラムが5°表示格子なので細かな角度分布の差は分からない。

### C：同じ降水環境にある写真の角度分布差（探索表示）

各種で**元野外出現のBIO12から定義した共通の表示格子**を使い、在来域と全導入域の各雨量表示帯で、画像角度0–180°の**条件付き分布全体**を比較した。写真30以上＋5°地域セル5以上の帯のみ表示し、他は欠測。**特定の幅や角度閾値を試したのではない。** 一貫した単方向の帯移動は図上で明瞭でないが、地域セル再標本化による各二次元格子の同時不確実性を算出したわけではないため、この可視化から「無関係」とは判定しない。

## 生態学的な現在地と次の推定対象

1. **再現性のある肯定結果は気候側**：両種の全導入域の野外出現は在来域より多雨（BIO12中央値 +217.4/+293.0 mm、独立の全ECDF地理セル感度でも方向を支持）。写真適格サンプルの降水ECDFも元出現ECDFと概ね近い。
2. **角度側は一律の導入後変化を確証せず**：全角度ECDFの地理セル同時感度帯はゼロを含む。新しい二次元可視化でも一貫した角度の単方向移動を見出せていない。
3. **地域混合は実際に重要**：*arvense*の39観察/8セルが8%の空間重みを持つ事実により、全球角度CDFの小さな偏りを「種内適応」と読むべきでない。*vulgare*は複数大陸に分布するため、北米一地域だけで全球導入域を代表させない。

本解析は**真の重力基準の頭花下垂、遺伝的可塑性、雨よけ機能を検証しない**。分布の形を見た今後に、必要なら撮影月/元観察QC・地域セル・カメラ姿勢を切り分けるが、既存の完全ECDFや主解析の気候シフトを置き換えない。
