## 4. 生態学的な結論とGEBへの帰結

**支持された事実：** 自生分類群を全球で合わせると、降水の多い場所の分類群ほど下向きに写る頭花が多いという**分類群間の共分布**がある。しかし、同じデータの地理構造を表現すると、その勾配は安定な地域内共通効果としては確認されなかった。特に東側優占の38–40分類群を除くと、BIO18の正勾配が消える。

**強い意味での「雨の多い地域ほど頭花が下向き」普遍則は現段階で支持されない。** 解釈としては、**地域ごとの分類群構成／形態分化と気候の共分布**を主に考え、雨による花粉保護は引き続き検証すべき仮説とする。地理調整が因果の全てを解いたわけではなく、気候と地理の強い相関・共通気候支持域・系統的非独立性は未解決。写真上の頭花角度は実際の重力基準での点頭ではない。

**投稿原稿への必須変更：** Abstract / DiscussionでBIO18のHolm有意を「全球地域を越えた共通の環境フィルター」として書かず、地理調整での消失・東側除外感度を説明する。弱い画像形質間相関はSIに保持するだけでよい。S2の花色×日射／標高は2種の独立した別の標本階層で、こちらは既存固定結果を保つ。前回BIO12の地理解析（2026-10-22）は別の雨量指標・共変量・コホートなので、新BIO18の数字と混ぜない。

**次の未解決の機構検証：** 同一分類群と気候支持域で核系統樹・地域区分の寄与を分離し、写真姿勢を現地の重力基準観察と照合する。系統独立な雨よけ適応の反復や遺伝的原因はまだ示せない。
