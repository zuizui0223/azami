# V4 S1・S2・H3c：旧結果を使わないX-only変数選択（2026-11-07）

**方法の区別：** 元のV4で既に有意だった変数、RF順位、Sparse PLS2負荷量、花形質の値を選択規則に入力せず、環境候補Xの情報量だけから各節別に変数を選択した。元3.1–3.3の回帰・Holm・H3cの確定結果は変更しない。花形質に対する「最適化」「有意性検定」はこの実行には含まれない。

## 客観的な選択規則（結果を見る前にソースコードへ実装）
- 既存候補X（S1気候22変数／S2気候11変数、標高別扱い）を分類群／地域セルで要約し標準化。
- 変数間の絶対相関0.85以上の重複を避け、元の標準化候補Xの共分散を**90%以上再構成**する最小限の変数集合をグリーディ前進選択。上限S1 12、S2 8。
- 24回のX-only再標本化で選択頻度を保存。**これはBoruta／VSURFでも花形質への予測性能評価でもない**。
- 元花形質コホートではなく気候候補がそろう元観測／セルを用いる。元Yの適格性・有意性は選択の入力ではない。

## 3.1 S1：分類群間・分類群内を別々に選択
元S1 313,350観測のうち22気候候補完備313,240観測。
- **分類群間（206分類群）：6軸、X再構成90.73%**。BIO11 → BIO12 → BIO10 → BIO19 → BIO02 → BIO17。
- **分類群内（163分類群・9,710分類群×1°セル）：9軸、X再構成92.50%**。BIO01 → BIO12 → BIO07 → BIO17 → BIO03 → BIO08 → 風速 → RSDS → BIO18。
- 既存の気候–頭花回帰効果とは別に、源データの分類群間／内の気候共分散の違いを示すX-only特徴選択。

## 3.2 S2：両域共通に用いる変数を、種別に選択
元S2野外観測297,622、各種在来／移入の5°/sine-latitudeセルを等域重み付けし、両域の環境分布の5–95%共通範囲に各域10%以上のセルがある軸のみ候補。
- ***Cirsium arvense*（在来198セル／移入77セル）：5軸、X再構成91.21%**。BIO12 → BIO01 → BIO15 → BIO04 → RSDS。選択後の気候で説明しきれない標高X分散22.73%。
- ***Cirsium vulgare*（在来129セル／移入91セル）：5軸、X再構成92.32%**。BIO12 → BIO01 → BIO15 → BIO05 → BIO18。気候で説明しきれない標高X分散79.51%。
- **標高の残差分散は花色への標高効果を測定したものではない。** 在来／移入間の花色勾配差に使う際は選択後も同じ調整変数を両域へ適用する。
