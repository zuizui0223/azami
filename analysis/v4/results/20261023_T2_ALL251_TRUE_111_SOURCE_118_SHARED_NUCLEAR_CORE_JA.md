## 現在地／肯定的結果

**S1元画像170,066件／WCVP受容分類キー244／原学名解析単位251を保持したまま、EAzami294に対応するMoreyra公開SRA 125 runの実塩基を品質監査した。** 同じ123 runで先頭120,000リードペアの核参照へのQ20品質付き深度が取得でき、分類キー単位で111分類群が測定済み。SRR30887185（C. esculentum）、SRR30887248（C. kirbense）は公開runが120kペアより短いため「未測定」とし、遺伝子不存在に置き換えない。

元著者Moreyraの公開HybPiper集計から独立に復元した、パラログ警告なし／高占有率の保守的241核候補を使用した。真正の著者手作業で選ばれた最終350座位そのものではない。

## 実証結果と未解決の進化学的課題

**肯定的なのは、同一の111分類群の実DNAを4倍取得すると、多数の種に共通する元核参照コピー候補が18から118へ増えるという明確な結果。** これにより全球種樹を組む配列入力の確からしさが進んだ。

ただし **Q20リードの同参照コピー一致 ≠ 単一コピーオーソログ認証 ≠ 完成した配列座位のアラインメント ≠ 全属の核種樹**。頭花EXIF画像縦軸は重力基準の植物学的下垂ではない。真の進化起源数・降水環境の関係・BM/OU/多最適値OUは、実質的に共通した塩基位置・コピー数/多倍体・voucher/QCを確認した核種樹、独立した頭花姿勢の分類がそろうまで未確定。

現段階の真の核系統の確認は独立北米NA63樹（下垂5、純下垂末端クレード4、姉妹群のBIO12方向は正2/負2）と日本EAzami38樹（植物学的頭花向き最小総変化6、UFBoot樹では4〜6）であり、実SRAの7標本101核候補から構築した暫定MLの分岐は核座位300回再標本化で一部82%〜100%再現した。[実行 #39876618341](https://github.com/zuizui0223/azami/actions/runs/39876618341)。

**次の核となる実証工程は、全111源標本とコア118参照を用いたQ20共通塩基座標の無補完抽出 → 本当に同祖な遺伝子コピーのフィルタ → IQ-TREE遺伝子樹／連結樹＋ASTRAL、そこへ251原学名・降水BIO12/BIO15と植物誌で独立採点した重力姿勢を接続すること。** EAzamiの294標本本体核解析は引き続き別の未完了なHPC主線であり、その全体結果を本118座位の部分リードの成果で代替しない。
