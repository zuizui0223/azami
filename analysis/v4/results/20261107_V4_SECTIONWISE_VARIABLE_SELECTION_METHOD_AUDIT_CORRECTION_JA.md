# V4 3.1–3.3 変数選択の再監査・説明訂正（2026-11-07）

## 訂正の結論
**2026-11-07の「3.1–3.3それぞれの最適な変数を選んだ」は過大な表現であった。** 完了したのは、節ごとの限られた候補に対する事後探索の予測・感度比較であり、各節の主要科学推定量について最適変数セットを決定した結果ではない。前回の結果数値は維持するが、推論の強さを修正する。元V4 S1/S2 Holm検定・H3c凍結結果は一切変更しない。

## 解析と対象の照合

### 3.1 — 形質別RFで「分類群平均」の予測変数を選択
- 実行コード: `analysis/v4/s1_traitwise_rf_subset_selection.py`、原S1実行 Actions #42371752668、匿名成果物 #13574532537。
- BIO01–19・RSDS・VPD・風の22候補。標高なし。各形質別にRF不純度重要度で順位づけ、3/6/10/22変数を内部3foldで選択、外側5foldで評価。真のRF条件付き置換重要度でもBorutaでもVSURFでもない。
- 選択モデル対22変数RF: 8形質中4でSkill上昇（向き・明度・円形度・solidity）；4で低下（彩度・色相・縦横比・幅CV）。
- **元3.1が求める分類群内の撮影地点間勾配・分類群間勾配の分離は選択手法に入っていない**。分類群平均の重要度は種内勾配の最適説明変数にならない。経度帯外への保留も今回の新規選択モデルにはない。

### 3.2 — 元4候補の部分集合を8層で別々に選択
- 実行コード: `analysis/v4/s2_native_intro_traitwise_subset.py`、原S2実行 Actions #42372471872、匿名成果物 #13574078187。
- BIO18・BIO05・RSDS・標高の4変数から15部分集合だけを比較（S2の22気候変数をスクリーニングしていない）。2種×在来／移入×明度／彩度=8組。撮影者×原セルの均等化と同一原12変数完備支持、内側3fold・外側4foldで地理セル保留。
- 選択モデルが元の4変数モデルの学習外Skillを上回るのは**8組中1組**。7組で悪化。変数選択の優位を主張しない。
- **在来／移入域で異なる調整集合を選んだ場合、係数を直接比較したり「勾配差」と呼ぶべきでない**。比較対象を同じ種×2域の共通支持域に揃え、共通の調整集合で `環境×移入域` を検定する必要がある。
- 注意：今回の元4変数デザインの気候標準化と月年項の選択は外側CV前に行われており、応答を用いた直接的な候補選択リークではないが、厳密なfold内前処理ではない。改訂版では学習側のみで推定する。

### 3.3 — 元3軸のleave-one-variable-out感度
- 実行コード: `analysis/v4/s1_h3_climate_axis_dropout.py`、元S1実行 Actions #42372039545、匿名成果物 #13574730357。
- 元のBIO12・BIO01・RSDS、ならびに3種の2変数集合だけを比較。BIO08、他のBIO/風速/VPDは候補に入っていない。RF/PLS2による変数選択ではない。
- 元の3変数モデルは1°・5°で強い正の類似性を再現。しかし1°の気候アナログ分類群ペアは3変数モデルで平均約227、2変数モデルで約339～548と、比較するサポートが違う。次元数に合わせた距離閾値の調整は同一ペア・同一実効気候距離の比較を保証しない。元3変数が**候補4組の中で比較的強かった**ことは示せても全球22変数の「最適集合」を決めていない。
