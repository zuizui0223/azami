# S1：種間比較の実装と、使用可能な定量データを使い切ったかの監査（2026-10-22）

**判定：向きについてS1で計測適格な観察値は全部使用済み。一方、元全写真・27形質・9環境変数をすべて使った研究ではない。** 244受容分類キーを244点の等種重みで回帰したのでもない。

[ソース別Git blob、全27項目、N、環境選定、種別偏在を固定した監査JSON](20261022_S1_INTERSPECIFIC_QUANTITATIVE_COVERAGE_AUDIT.json)

## 1. 現在のS1「種間係数」は何を比較しているか

原コード：[観測単位・種クラスタモデル](../observation_models.py) ／ [全観察の種平均と各地点の差への分解](../native_trait_models.py)。

原 iNaturalist の野外種同定／写真測定を、Kew WCVPの受容分類キー（accepted_key）でまとめた。「species」は厳密には**受容キー**である。

1. 原665,115観察をWCVP/TDWG分布・野外・公表座標で分類し、**自生域313,350観察・306受容キー**を固定する。元ソースの1,122,854は**写真リンク数**で、独立した角度計測数ではない。
2. 元のCHELSA候補6変数に対し、種間・種内・元観察レベルで形質結果を使わず相関/VIFを監査。**BIO1・BIO4・BIO12・BIO15・RSDS**の5項目を同時投入し、BIO1と強く重なった**VPDだけを除く**。元ファイルにはそのほか風、GSP、NPPがあったが主たる直接気候モデルには入れない。
3. **各種の環境平均Ē_sは、角度が測れる観察だけではなく、在来域の元観察（環境が有効な地点）全体で算出する**。写真で向きが測れた観察 i の同じ環境値E_isとの差 E_is−Ē_s を種内成分とする。5環境×種平均/種内偏差＝**10の条件付き固定効果**を同時に含む。
4. 従属変数は **EXIF画像上の連続頭花角度**。有限値かつ適格な**170,066観察／244受容キー**を全使用。各種のランダム切片を持つREMLで推定し、種クラスタのスコアによる区間・共同検定を計算する。**種の観察数が異なるため244種の等種重みOLSではない。**
5. この10項目の結果を元の温度、雨、季節、日射の単位に換算。3つの主要形質モジュール（向き・色・輪郭）×5環境×2階層、計**30件の共同検定**をHolm補正。主たる種間BIO12効果**+0.4382°/100 mm**、95%**+0.2058～+0.6706**、Holm P=.00531。種内BIO12 **−0.0443°/100 mm**、95%**−0.2188～+0.1303**。すべて**観測上の関連**であり、雨の適応的選択や物理下垂の実測ではない。

## 3. 使える定量形質は全部使ったか

同じ**313,350自生域観察**の保存済み定量形質の27項目を [原集計監査](20261022_S1_INTERSPECIFIC_QUANTITATIVE_COVERAGE_AUDIT.json) で検査すると、**18項目は解析適格データを持ち、9項目は適格データがない**。定量項目は互いに独立な27の進化形質とは限らない（例：色相sin/cosは1つの円周形質、輪郭4指標は相関する）。

| 定量形質群 | 原データでの適格観察N | 受容キー | 同じ5気候変数のV4モデルでの扱い |
|---|---:|---:|---|
| 頭花の**画像角度**・1指標 | **170,066** | **244** | **S1主応答として使用** |
| 花色（明度・彩度、色相sin/cos）・4指標 | 186,439（色相186,390） | 244 | 色モジュールで**4指標使用**。S1の向き応答には混ぜていない |
| 頭花輪郭・4指標 | **176,048** | 243 | 輪郭モジュールで**4指標使用**。S1と別の形質として扱う |
| 総苞体・総苞片輪郭プロキシ・9指標 | **1,303** | 111 | **2指標をSIモデルに使用**、残り**7指標は現5気候モデルでは未投入** |
| 総苞表面テクスチャー・4指標 | 有限値570／適格0 | 0 | 適格性未達・解剖学的検証不能、**主モデルには使用不可** |
| 花部可視率・色組成比・5指標 | 0 | 0 | 現データでは未測定、**使用不可** |

**27中：解析可能18項目、5気候モデルで使用11項目、適格だが未モデル化7項目、解析不適格9項目。** 後者9項目を捨てたというより、5項目は値がなく、4項目は画像値だけあってもQCによる適格値がない。総苞の輪郭突出値を実際の総苞片基部‐先端の開出角やトゲ長さへ代入することもできない。

これは「種間比較には全データを使った」という意味では**NO**。ただしS1の狙いを年降水×頭花向きに絞る限り、花色・輪郭を単に共変量へ加えることがより良い推定になるとは限らず、独立した関連または撮影人工物の対照/SIで位置づけるのが妥当。

## 4. 定量的な環境情報も全部ではない

現在の自生域環境表には、**BIO1/BIO4/BIO12/BIO15/RSDS/VPD/風/GSP/NPPの9列**があり、9列完備は312,001観察／種平均完備303受容キー。直接気候の候補としては最初の6列を選び、**VPDはBIO1との高相関**（元観察r=.909、等種平均r=.862、種内r=.812）で規則どおり除外。主S1は最後の**5列**だけを使用している。風・GSP・NPPは現在の主推定対象として選ばれず、存在しないわけではない。

この5変数選定は元環境の種間・種内の相関やVIFに基づくもので、形質の有意性を見て選んだわけではないが、**既存の探索結果を知った後に修正された解析契約**であり、完全な独立事前登録ではない。

## 5. 元写真の定量値は全部測っているか

**NO。** 元665,115観察には合計1,122,854の写真リンクがあるが、S1が使用したのは**観察単位へ集約・QCを通過した170,066件の角度**であり、全写真リンクを独立の頭花角度として計測したものではない。

WCVPの原学名が混在する7受容キーを除いた**169,612の角度適格観察のうち77,977観察には元写真が2枚以上**ある。しかしこれは複数画像に**同じ頭花**が写ることを保証せず、同一頭花に対する二重・反復計測の精度は**確認0組**。撮影者・撮影姿勢・発達段階・画像の欠測メカニズムは未解決。残る約14.3万の自生観察の向きの取得可否は、**元画像の再検出/QC理由**を調べる必要があり、単純な欠損補完は禁止。

## 6. この後に行うべき定量データの有効活用

**優先1（主線・種間比較の強化）：** 244キーの観察単位推定とは別に、原学名衝突なし**237受容キー**の**等種重みの種平均回帰**と、観察単位の混合モデル、撮影者×セル均等化モデルを同じ5気候のBIO12/BIO15で並記する。元の主推定を一方にすり替えない。237キーの等種重み探索は既に実行しており、未検証の撮影条件や本当の重力角を除けばBIO12の方向は正。**最大標本2種が約48.6%を占める**ため、その差を説明することが重要。

**優先2（補完可能な向き画像）：** 受容キーはあるが現在の向きがない**62キー**と、143,284の向き不適格観察の**欠損理由・元写真の可否**を確認。約112万リンクを全部「有効な生物角度」に昇格できるとは考えず、優先QC再計測、撮影者・花序数・同一頭花IDを保持する。

**優先3（形質の横断利用）：** 他の色4・輪郭4・総苞形態9を**各々の解析適格数に応じた別モジュール**で使い、反復計測と形質構成の相関を検証する。全27項目に**完全ケースを強制して157,779より少ない小標本へ落としたり、総苞1,303件をアザミ属全球の全頭花形質の代表標本として扱ったりしない**。

**現在の判定を一文で：**「S1は向きのQC適格な全17万観察を使用したが、種等重みではなく、元写真全件や定量27項目・環境9列すべては使用していない。S1の種間正相関は、**分類群の環境平均と同種内の偏差を区別した観察単位の条件付き関連**であり、真の向きの適応進化を証明しない。」
