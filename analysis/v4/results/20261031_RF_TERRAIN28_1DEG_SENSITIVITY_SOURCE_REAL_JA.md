**実測済み、ただし事後的な探索的感度分析。GEB原稿・元S1 80検定・S2 128検定・H3cの数値は未変更。**
元データの出所・実行は [GitHub Actions #41190720211](https://github.com/zuizui0223/azami/actions/runs/41190720211) **SUCCESS**、匿名集計 artifact **13038349385**（実ラスタ＋個票は非公開）。

## 1. 認証・観測単位
- 元S1の **313,350** 観測をソースSHA・暗号化認証で復元。CHELSA v2.1、WorldClim 2.1 DEMを元座標でピクセル取得。
- DEMの標高と既存の7変数外部レイヤの標高がともに有効な **311,691**観測で完全一致（**不一致0**）。全5地形指標の有効観測 **303,464**（約96.8%）、欠測を補完しない。
- 説明変数は既存CHELSA BIOCLIM 21、元S1のVPD＋地表風を加えた **23** に、WorldClim DEMから計算した傾斜・起伏・TPI・northness・eastnessの **5** を追加した **28**。因果的に独立した28機構を意味しない。
- 1分類群×**1°緯度経度セル**の写真中央値、各セル最低3写真、各分類群最低40写真かつ8地理セル。対象は各形質**55分類群**。地形追加による欠測で、元23変数の1°・3写真診断の**56分類群**から1つ減る。同じ完成ケースで23/28を学習・評価。
- 元の5°解析（26分類群）からの1°変更は既存の結果を見た後の**posthoc**感度検査。地理粒度・分類群組成・サンプル重みが変わるので、異なる粒度間のSkill差自体はモデル改良効果ではない。

## 2. 同一1°コホートでの直接比較

Skill = 1 − weighted held-out model SSE / train-fold weighted constant-mean SSE。**負値は定数平均より悪い予測**。未知分類群は分類群数均等化GroupKFold（各fold 11分類群）、未知地域は3経度セクター丸ごと除外（同一分類群が学習/評価双方に入り得る）。80 trees、min_samples_leaf=5、max_features=0.75、permute 2 repeats。P値やCIは新規推定していない。

## 3. 凍結5°解析と照合（異なる解析集団、直接的な効果比較ではない）

同じsource-real runの5°結果と既存ドキュメント [5°元解析](20261031_RF_TERRAIN28_5DEG_SOURCE_REAL_JA.md) を保持。5°では各形質26分類群、 angle +0.0268（未知分類群）/+0.0201（未知地域）、chroma −0.0068/+0.0332、aspect −0.0305/−0.0864。1°ではangle未知分類群、chroma未知地域のΔの符号が反転する。

検討すべき一般問題は「変数を増やせば地域を超えて花の形態が予測できるか」であり、**現段階のRFはそれを支持していない**。これは元論文のS1 BIO18相関やH3c局所気候アナログの結果を否定する検定ではない。頭花角度はカメラ縦軸基準、彩度は未校正JPEG、縦横比は2次元投影である。

## 4. 次段の意思決定

1. この1°結果を新たなconfirmatory ecological discoveryにはしない。5°・26分類群の元結果は上書きしない。
2. データ処理の単位に基づく追加候補として、環境が説明する**同種内の局所差**と、未学習種への絶対形態予測を分ける。現行の未知分類群Skillのみで気候との局所相関の不在を主張しない。
3. さらに土壌・植生を足す場合、元原稿と解析分離を維持し、ソース・単位・期間・コホート欠測を先に監査する。非気候変数による追加予測精度が低ければ「増やせば良い」とは主張しない。
