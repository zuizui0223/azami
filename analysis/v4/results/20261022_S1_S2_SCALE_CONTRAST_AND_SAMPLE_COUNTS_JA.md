# S1＋S2：種間の降水–頭花角度の正の関連と、湿潤な進出域における種内の頭花変化の不明瞭さ

**2026-10-22／S1・S2の既存実測結果を一つの階層的な生態学的対照に統合。** 地理構造調整・仮配置祖先状態・反復進化数を今回の主解析・主張には含めない。数値は取得済みソースの相互照合であり、今回新たな統計推定を行ったわけではない。

## 1. まず生態学的な二階層の主結果

**S1・種間（自生域）：** 自生域のアザミ属244受容分類キー、画像角度適格170,066観察では、同時調整されたBIO1／BIO4／BIO12／BIO15／RSDSモデルで、年降水量BIO12が100 mm多い分類群ほど、画像縦軸に対する頭花角度が **+0.4382°** 大きかった（種クラスタ95%区間 **+0.2058～+0.6706**、Holm P=0.00531）。一方、同じ原データの**種内**BIO12係数は **−0.0443°/100 mm**（95% **−0.2188～+0.1303**）で明瞭な勾配は支持されない。

**S2・同じ種の在来域→進出域：** 世界のWCVP/TDWGで明示された全進出域を対象とした2種比較では、野外出現記録の年降水量中央値が **両種とも進出域で上昇**。しかし、画像角度の分布中央値は両種で各1°小さくなるだけで、90°以上の画像角度が両種で一様に増えるわけでもなかった。**「湿潤な出現ニッチ占有へのシフトは観測されたが、同じ種で頭花向きが対応して下向きに変わるという一貫した傾向は観測されない」**という種内の対照であり、「角度が変化しない／進化的に固定／雨適応が起きていない」と結論したものではない。

**S1とS2を一緒に読むと：** **分類群間でみられる環境と頭花方向の対応は、新しい湿潤環境への進出に伴って同一種内にそのまま現れるとは限らない**。これがS1（広域の種間パターン）＋S2（2種の種内進出域比較）による**尺度の対照**である。遺伝的固定・適応速度・雨よけ機能の因果機構を示すものではない。

## 3. 生態ニッチと頭花向きの同時比較（在来→全進出）

| 頭花画像角度の分布中央値（1°ビン） | **68→67°** | **64→63°** |
| 画像角度90°以上の割合 | 35.07→31.24% | 25.38→25.92% |
| 90°以上割合の進出−在来差 | −3.82ポイント | +0.54ポイント |
| 同割合差の空間セル再標本化95%感度区間 | **−8.90～+0.36** | **−3.59～+4.46** |

観測地点の**年間降水量中央値**と**頭花画像角度分布中央値**は、元データ由来だが完全に同じ適格個票の中央値ではない。前者は頭花画像の計測適格を条件にしない野外出現データ、後者は実際に画像角度を測れたデータである。さらに両結果は観察努力・気候利用可能域・撮影向きの違いを完全には補正しない。出現先でより湿潤な気候を占めたという事実は**気候ニッチ進化・湿潤選好の進化を意味しない**。

## 4. 結論の限界と論文本文での表現

- **支持済み：** 全球の自生域では**種間**に年降水量と画像上の頭花角度の正の関連。2種の**同一種**では、進出域の年降水量中央値が在来域より高い。進出域で頭花画像角度が共通に大きくなる傾向は現在確認できない。
- **未支持／未確定：** S1の種内BIO12勾配、BIO15の独立主効果、2種が厳密に向きを保持したという等価性、湿潤環境への進出による遺伝的分化・可塑性・雨よけ機能。
- **補助・SI：** 以前の系統・撮影者・地理感度解析は保存し、中心の記述的2階層パターンへ混ぜない。地理的な種構成が雨量と角度の関係に寄与し得ることは**因果解釈の制約として維持**し、あたかも地理から独立した降水効果が示されたかのようには書かない。

**本文に使える主張：**「自生域のアザミ属では頭花の連続的な画像角度が年降水量に伴って分類群間で大きくなる傾向が認められた。一方、十分な出現・画像データのある *C. arvense* と *C. vulgare* では、全進出域の観察地点の降水量中央値が在来域より高かったにもかかわらず、頭花画像角度の分布は共通の下向き方向への変化を示さなかった。種間での気候–形質の対応が、新たに湿潤な地域を占有する同一種内でそのまま現れるとは限らないことが示唆される。」
