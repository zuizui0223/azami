## 全球での標高の役割と推定対象
標高は地理条件であると同時に、気温・降水・日射・積雪等へ影響する気候形成要因であり、独立の気候原因ではない。緯度・経度は日長・大気循環・海陸配置の代理になる。世界全体で「標高が1000m増える」単一係数は、地域間の分類群構成、気候、観測努力の違いを強く拾い得る。

1. **気候応答の軸：** 標高なし22気候変数から構築したPLS1/PLS2を主要説明軸とする。
2. **標高の残余情報：** 同一分類群・同一位置セットで `Y ~ 軸1 + 軸2 + 空間項` と `Y ~ 軸1 + 軸2 + 空間項 + 標高` を比較する。標高に固有の追加説明力が得られた場合でも、局所地形・土壌・積雪など未測定環境と地域史が含まれると明記。
3. **地域内の垂直勾配：** 地域固定効果／地理スプライン・分類群効果の下で、分類群内（各分類群の観察地点平均との差）と分類群間（種平均）の標高差を分ける。各地域に垂直高度の観測範囲がない場合は推定不能とし、全球から機械的な共通傾きを外挿しない。
4. **地理を独立の因果説明としない：** 緯度・経度は地理非独立性の感度分析・ブロック保留に用いる。経度は循環変数として扱い、180°境界を直線としてモデル化しない。
5. **比較に必要な支持：** 軸と標高の独立変動が地域内で十分あるか、重なった気候・標高サポートおよび設計行列の条件数を確認。標高をモデルから除外しても、気候変数に標高に伴う気候情報は残る。標高を足した結果だけで直接的標高因果効果とは呼ばない。

## 3.1 気候軸×種間／種内
- sPLS2のX標準化中央値・SD・線形投影行列（`W(P'W)^{-1}`）を**学習分類群のみ**から求め、同じ変換で検証分類群の22気候変数を軸スコア化する。第2成分を生のX×第2重みだけで投影してはいけない（deflation）。符号は学習側の事前ルールで固定。
- 種間差：種平均の軸スコアと形質平均を比較。種内差：各観察点のスコアを分類群内中心化し、分類群間との効果を区別。1種1点の影響で見かけの種内勾配を作らない。
- 標高なし軸のみ、+標高、+空間、地域除外の感度を**同じ写真・分類群支持**で比較。生物学的角度はカメラ縦軸基準であり、重力基準の実測ではない。

## 3.2 S2在来／移入への軸転移
- 元S1で軸を学習する際、S2二種と元S1で重複するソース観測・分類群をトレーニングから丸ごと除外する。凍結軸をS2の全22元画素気候に**学習し直さず**投影する。S2で22変数が取得できない場合は、4変数の代理軸を同じsPLS2軸だと称さず未推定扱いにする。
- 2種それぞれの在来域と移入域で、軸スコア×移入域の交互作用を共通気候支持域で評価。撮影者・時期・空間セル重みを元S2と整合させる。元のS2「導入域の標高×明度 β−0.1737」等は保存し、軸の新しい感度解析により削除しない。
- 標高はモデル主軸から外し、元のS2の標高効果が同じS2支持集団で軸・地理を追加したときにどこまで残るかを別表で示す。交互作用の有意／非有意は進化的変化・不変の証明としない。

## 3.3 H3cの気候アナログ
- H3cの気候類似度を元BIO12/BIO01/RSDSの3軸だけでなく、凍結されたsPLS2の2軸による距離で再評価する。元1°63分類群・5°31分類群のソース支持と3形質の同時観測を維持。
- **Yを使ってsPLS2軸を学習した同じH3c分類群をそのままテストしない**。両方の比較分類群を学習から除くfold／タクソンペア単位cross-fit、または一度もH3cに使わない分類群だけで軸学習。類似度閾値は形質に依存せず学習側の気候距離分布・支持ペア数から前もって固定し、H3cのPが最小になるよう選ばない。
- 元の同一分類群内で形質ベクトルを置換する帰無、各分類群ペア等重み、1°・5°、地域ペアの支持数を維持。2D対3Dは次元数の差があるため距離閾値・マッチ数を揃えた比較を併記。新しいH3cは探索的で元H3cのHolm P=.010とは別。
