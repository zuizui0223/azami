# S1 土壌6変数：28→34 RFの固定予算・1°セル小規模探索（2026-10-31）

**実装・合成試験段階。本物の34変数RFの結果が出る前に、肯定的な予測改善と主張しない。** GEB凍結原稿、S1/S2 Holm結果、H3cおよび5°/1°のこれまでのRF結果は不変とする。

## 出発点（確定した事実）

- SoilGrids v2.0公式WebDAVの**0–5cm・Q0.5**の6 VRTは、公開テストで各原本バイトSHAを確認済み。
- 非公開S1を認証した**36地点の実測パイロット**では、6層それぞれ30/36地点に有効値、**同時有効30/36（83.3%）**。物理範囲外ゼロ。[元S1出典記録](results/20261031_SOILGRIDS_S1_PRIVATE_36POINT_SOURCE_PILOT_JA.md)。これは本S1全体の被覆率ではなく、RFの結果でもない。
- 現行の28変数モデルはCHELSA BIOCLIM21、原CHELSA VPD/地表風の2、WorldClim DEMから計算した5で構成する。土壌6の追加は**`terrain28_soilmatched → terrain28_plus_soil34`**。既登録の`soil39`は未取得のTerraClimate群を含むので使用しない。

## 事前固定した対象選定・データ粒度

1. 検証済み313,350元S1から、元の写真QCと**28変数完全ケース**を用いて1°緯度経度の分類群×セル中央値を作る。**最低3写真/セル、8セル・40写真/分類群**を満たすセルだけを対象とする。画像における向きを先行評価対象とする。
2. 各分類群について分類群名とセル識別子をハッシュ化した固定順位から、**最大14セル/分類群**を選ぶ。これにより写真の多い分類群へ取得量が偏るのを抑える（形態値による順位づけは禁止）。
3. 選ばれた各セル内で、元の`obs_id`に対する独立した固定ハッシュ順位から**3つの元写真位置**を選び、正式な6つのQ0.5土壌VRT原画素を採る。最大3,000写真位置までの硬い上限を設け、超過すれば停止する。**未取得地点・海岸・島を近隣で補間しない。**
4. 6変数が**同じ写真位置で同時有効**なサンプルを数え、**3地点中2地点以上**が有効だったセルで6土壌変数の中央値を作る。元の28環境変数・写真形質のセル中央値は従来の完全観測から作り、土壌だけをこの明示した固定位置サブサンプルで評価する。したがって土壌値はセル内の3画素近似であり、全写真地点の土壌中央値と同義ではない。
5. 土壌有効セルだけで分類群≥8セル・総写真≥40を再判定し、**25分類群未満**、あるいは3経度セクターにデータがなければRF適合を行わず不足報告を出す。試験時点で閾値を都合よく緩めない。
6. **28対34RFは同じ土壌有効セル**で、分類群均等5分割と未知3経度セクター（各評価側に5分類群以上）を使って比較する。80木・leaf5・max_features=.75・環境群置換反復2は変更しない。陰性結果を含めて報告する。

## 透明性と限界

- 土壌は**地理モデルによる予測土壌値**であり、アザミ個体が生育する根圏の実測値ではない。観測日の土壌状態や独立した適応機構とは解釈しない。
- ベースと追加モデルを同じ写真・セルで比較することは保証するが、今回の**選定セルは従来の1°・55分類群の完全なセル集合ではない**。これら異なるコホート間の絶対Skill差を「土壌の効果」と比較しない。
- VRT原本のSHAは検証する。ただしWebDAVが配信する**基礎GeoTIFFタイル全体のバイトSHAは取得・固定していない**。これを完全なバイト再現性と呼ばず、source identityの残存リスクを記載する。未確認のWCSや違う深さを混在させない。
- 公開するのは分類群数・セル数・元写真数の匿名合計、ソースSHA、元画素の有効数、保持セルの集計スキルのみ。元写真/観測ID、撮影者、分類群名、経緯度、個別の土壌画素/推定値、非公開アーカイブ、ラスタタイルはPR/Artifactへ出さない。
- 設計は既存RFの結果を見た後の**探索的・事後的な拡張**であり、これで新しい独立な確認的仮説検定を構成したとは扱わない。土壌の影響を主張するには地理的・系統的・写真測定バイアスの検証が別途必要。

GitHub Actionsは**PR #167の同一リポジトリ内専用の保護ジョブ**で実行し、元S1・DEM・土壌抽出をすべて保護作業領域に閉じ込める。土壌の読み出しは外部の公式WebDAVへのラスタタイル要求を伴い、同サービスは要求タイルの範囲を技術的に知り得るが、元の観測ID/分類群名・完全な経緯度表は転送しない。
