# H3c：24セル抽出×独立乱数系列による推定安定性（2026-10-29）

元のH3cは1°・5°で24回の8セル抽出と199回の分類群内置換を用い、気候類似地点での頭花3D距離の改善を報告した。その後、別の乱数で同じ24セル抽出・99置換を行うと、**1°セルの元閾値0.9では名目P=0.540**となった。一方、5°では名目P=0.010だった。これは抽出の乱数に結果が依存する可能性があるため、同じ元データと気候閾値0.9、KDE幅0.75を維持し、**抽出乱数による推定安定性を全6系列で評価する**。

- 分類群：元S1の同一写真3形質QC。1°支持条件で63分類群、5°で31分類群。8セルを分類群ごと等確率で抽出。
- 評価の単位：各独立乱数系列に24回の8セル希少化、99回の分類群内3D形態ベクトル置換を適用。6系列のseedは20261029 + 10000×(1,2,3,4,5,6) + 解像度で**事前固定**。6系列と元の結果をすべて表示する。モデル・気候距離・KDE幅・対象3形質は一切再選択しない。
- 各系列の距離改善（観測−帰無平均）、そのP、密度重複の観測−帰無平均、そのP、および気候アナログを持つ分類群ペア数を出力する。6系列の方向安定性（正方向の系列数、最小・最大・中央値）を報告。系列ごとに名目Pを比較するが、**複数系列のPを独立進化の反復・Holm有意の追加確証として足し合わせない**。
- 源泉の位置・撮影者・個別分類群同定は出力しない。元S1 80/S2 128検定族、3.1/3.2、元H3c探索的Holm-2値を改変せず、その新しい**再標本化不確実性**を3.3解釈へ統合する。
- **結論基準**：元と似た正の方向が6系列で反復する場合のみ乱数依存性が限定的と解釈。方向や名目支持の変動が大きい場合は「探索的な局所的表現型対応は一つのサンプル抽出仕様で見えたが、頑健性は十分でない」と明記する。これは有意結果を捨てる操作ではなく、観測標本支持を適正に記載するための検証。
