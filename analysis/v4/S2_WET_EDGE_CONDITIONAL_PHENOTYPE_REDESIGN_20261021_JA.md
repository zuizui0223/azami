# S2再設計：広域分布種の「湿潤ニッチ端への進出」と頭花角度分布

**2026-10-21・解析設計改定。これは事前の推定対象と停止条件の文書であり、新しいS2実測効果ではない。** 既存の数値レシート、S1、凍結V3/GEB、T2/T3を改変しない。

## 0. 中心問いの置き換え

旧S2の「在来域の平均気候・平均角度 vs 導入域の平均気候・平均角度」「2域の単一線形BIO12傾き」のみによる結論を**主解析から降格**する。広域分布種では、地域の平均降水量が増えても既存の在来湿潤ニッチ内への記録の再配分で説明できる。新しい湿潤条件への進出が起きた局所集団の頭花角度変化は、他地域との平均で相殺される。

**新主質問：同種が自生域で占有していた湿潤側の環境ニッチ端、またはそれを越える条件に進出したとき、画像上の頭花角度の確率分布（上向き側・中央値・下向き側）は局所的に変わるか？**

観察データでは「進出前後の同じ遺伝系統の変化」は観測していない。よって結論の語は **wet-edge occupancy-associated orientation distribution** とし、「導入による適応進化」「可塑性」「固定」は独立実験・共通圃場・導入源集団の遺伝情報なしには確定しない。

## 1. 本当に「新しい多雨ニッチ」なのかを先に決める

**地理平均を使わず、元観察地点ごとの気候を比較する。** 確認済み二種 *Cirsium arvense*、*C. vulgare* を独立に分析。自生域／明示導入域のWCVP・TDWG状態は元665,115観察の判定を再利用。**気候ニッチ推定には画像角度の有無で選んでいない**2種の元野外297,622観察を使い、各種の自生域、各導入大陸、WCVP利用可能環境背景を独立に確保する。既に完了した全球CHELSA五変数元画素／WCVP背景85,414点の解析を使い、部分キャッシュPCA-envには戻らない。

- 一次曝露：**BIO12年降水量**（元CHELSA約1km）。副曝露：BIO15降水季節性。BIO1・BIO4・RSDSは競合する気候要因。別に撮影季節・年・地域／撮影者／画像QC。
- **湿潤端**：自生域観察の空間／元投稿者均等化BIO12分布の95パーセンタイルを事前境界とする。90／97.5パーセンタイルは感度であり、有意性により境界を選び直さない。これを「種の真の気候許容限界」とは呼ばない。
- **多変量の占有域**：同じ5環境で、WCVP背景気候の利用可能性で補正した自生域出現気候密度（PCA-env 2D）と、**元5変数での**近傍距離／密度支持を別々に評価する。D=0.474/0.442 は全域の重複の記述であり、個々の地点の「新奇」判定に転用しない。2D軸外の気候情報を省略しない。
- **湿潤のみの比較可能性**：BIO12以外の4変数 BIO1/BIO4/BIO15/RSDS（Z）を揃える。**BIO12を含めた5変数全てを一致させては、まさに調べたい湿潤端の新条件を消してしまう。** 5変数共通範囲は別の環境内転移テストであり、湿潤端テストの主な入口にはしない。
- 観察条件の層：①「自生域の既存気候と類似、低～中雨」②「自生域で既知の高雨域」③「**自生域の湿潤端を越えるがZは対応可能**」④「湿潤端を越え、**Zまで新奇**」⑤「乾燥側の新奇」；③が湿潤端の主要比較。④は「降水だけの効果」と識別できないため記述・保留、⑤は負方向の対照。
- 環境の新奇・既存・被覆は画像の向きの値を**一切参照せず**固定する。年降水増加（中央値+217/+293 mm）と新奇な湿潤端の観察割合は別々に報告する。
- 可能なら将来、**開花期の月別降水**と強雨日数／降雨強度を別の曝露として事前定義する。現行CHELSA年値は開花日の降雨ではなく、月別12値も現時点で再結合していない。取得しないまま開花期雨の実証と言わない。

## 2. 頭花の「平均角度」ではなく**条件付き分布**を推定

観察単位は保存済み画像計測とそのQCを持つ **観察（頭花／写真／観察のIDを混ぜない）**。在来域と各導入大陸の別々の環境層で以下の条件付き分布を比較する：

`F_s(a | R, Z, r, c, month, year, observer, site, QC) = Pr(image-angle ≤ a | ...)`。

**主要評価項目：**
1. 画像角度の条件付き分位点 **Q10, Q50, Q90** とその降水に沿う曲線（一次は**Q90の変化とQ10–Q90の幅**、併せて他分位点も必ず報告）。高い角度は「画像上で下向き寄り」を意味するだけで、重力基準の下垂率ではない。
2. 同一条件の**分布全体の差**：経験CDFの差と1D Wasserstein距離 W1（絶対的差の大きさであって方向を持たないので、必ず分位点の符号と対にする）。
3. **画像上の水平越え率** `Pr(image_angle >= 90°)` は直感的な感度解析に限る。撮影姿勢の独立校正なしに「実際の下向き頭花率」と呼ばない。元測定誤差に敏感なら主要結果から外す。

**主対照：** 同じ種・同じ導入大陸内で、③新奇湿潤端と②既知の湿潤側／①通常雨のうち**Z・月／年・写真条件・地域空間が重なる観察**を局所マッチングまたはoverlap weightingで比較する。環境距離を事前固定してから角度を開示する。距離調整はZにのみ行い、R（BIO12）を含めてマッチしない。十分な相手がない場所は**no analogue / not identified**とする。

**補助対照：** ②に相当する気候の自生域vs導入域をZだけでなくRも揃えて比較し、「同じ気候でも撮影域が違うと画像角度分布が変わるか」を監査する。これは地理差の検査であって元祖先集団からの進化差ではない。自生域内・導入域内のそれぞれの雨に沿う条件付き曲線を観測された支持範囲だけで比べる。

**推定モデル候補：** `image-angle ~ smooth(BIO12) × range/continent + smooth(other climate) + observation-month/year + camera/QC + cell/observer hierarchy` を分位点回帰・分布回帰・条件付き重み付き経験CDFで相互確認。高次元の気候スムーズを無制限に増やさず、2種ごとに事前固定する。統計量は**観測のある気候帯**でのみ表示し、外挿した直線を「新奇ニッチへの転移」と呼ばない。

## 3. 生態学的に見たいパターン（**すべて仮説**）

- **方向ごとの再配分**：平均は不変でもQ90だけ大きくなり、高い画像角度の頭花が湿潤端で相対的に増える → 高角度側の占有率変化の候補。
- **分布全体の移動**：Q10/Q50/Q90とも上昇 → 一方向の画像角度差がより広く分布する候補。
- **分散だけの変化**：Q10低下・Q90上昇、Q50ほぼ同じ → 局所条件での表現型の幅の変化候補。
- **気候が変わっても分布差を識別できない**：観察力と誤差を評価したうえでのみ効果の上限を報告。単なる非有意を「固定／可塑性がない」としない。
- **写真の見え方の変化**：QCや撮影姿勢で結果が消えるなら生物学的分化として採用しない。

①～④が示すのは観察の分布変化であって、現地選択による進化・創始者効果・遺伝的フィルタリング・表現型可塑性を写真だけで区別したものではない。

## 4. 画像取得・空間的擬似反復・欠測の処理

1. **二つの分母を公開**：形質選別なしの野外気候出現（297,622）と、向き測定可能な観察（元二種173,737、日付＋observer×5°セル一意で94,060）。分類群×地域×雨レジームごとに写真角度の測定成功率を調べる。測定成功が雨・場所・撮影者と関連する場合は、傾向スコア／選択重みによる感度を行い、極端な重みなら推論を停止する。未測定を0度にしない。
2. **有効標本は「地域セル」で数える**：マッチした観察数だけで精度を主張しない。例：過去の北米・在来95%超は *arvense* 576観察／21個の5°セル、*vulgare* 809観察／19セル。これは写真が何百枚あっても独立な湿潤端地域の反復が少ないことを示す。5°は集約・ブートストラップ、近傍一致にはより細かな独立空間ブロックを使い、同一観察・撮影者の重複を許さない。
3. **先に診断、後で推定**：層別ごとの Z 共通支持、撮影者・セル数、有効標本数(ESS)、気候幅、季節・写真品質欠測、同一cell外検証可能数を**向き効果を見る前に**集計。足りなければ無理にW1やQ90の確証区間を出さない。
4. 独立した5°空間セルを単位とした**地理ブロック再標本化／leave-one-region-out**を基本とし、投稿者の集中・画質・花期・気候背景の平滑化幅、元の未校正角度の感度を検証。写真1枚を1個体・1頭花の遺伝的反復とは呼ばない。
5. **独立原画像QC**：両種 × 自生／導入 × 通常雨／湿潤端 × 大陸を層別し、同一頭花の複数写真、花柄と水平・重力参照、カメラroll/pitch、開花段階、切り出し失敗を二重盲検監査する。何も校正できない場合、結論は画像角度分布に限定する。

## 5. この設計が旧S2とどう違うか

| 比較 | 旧S2 | 新S2の主設計 |
|---|---|---|
| 気候 | 大陸・分布状態の中央値、1本の直線傾き | **自生域の湿潤端を越える観察・局所気候軌跡** |
| 占有環境 | 5変数全部の共通範囲で限定（在来側2.74/7.37%しか残らない） | **調べたい雨をマッチ対象から除き、他の4軸で比較可能性を保証** |
| 頭花 | 平均画像角度 | **Q10/Q50/Q90・CDF・W1・上側分布の占有** |
| 比較 | 自生域平均 vs 導入域平均 | **同一種・同一大陸内の湿潤端 vs 気候類似地点、補助で自生域湿潤端** |
| 主張 | 転移スキル不足から保守性を推測しかねない | **湿潤端での条件付き形質分布差と、測定できない範囲を分離** |

## 6. 実行順（これより前の旧「非転移」結論を更新しない）

1. **A / angle-blind wet-edge ledger**：原野外全観察から気候層・背景・各層の観察／元投稿者／5°セル・カメラ／花期情報の欠損を計算。湿潤端の生データ支持が足りるか判定。**現時点で未実行。**
2. **B / within-continent conditional phenotype**：③vs②・①の比較可能なZと季節／QCの層だけで、Q10/Q50/Q90・CDF・W1を源とcell hashを固定して推定。撮影者／地理ブロック感度。**未実行。**
3. **C / native-edge external check**：②の在来vs導入の条件付き分布と湿潤端の占有密度、既存旧S2の傾き/平均角度は二次参照値に下げる。**未実行。**
4. **D / measurement gate**：原画像を盲検独立監査し、雨×画像角度差を重力基準・撮影姿勢誤差と分離。**未実行。**
5. **E / optional flowering-rain**：月別雨の12枚と開花期の独立判定が揃った場合だけ、BIO12との競合予測を事前固定して実行。**未実行。**

**既存実測の正確な置き場所：**
- 全球背景補正PCA-env D=0.474 (*arvense*)、0.442 (*vulgare*)、年降水中央値の増加約217/293mmは、**気候背景の出所と地理的再配分の実測値**。単独では新奇な湿潤端と形態変化を意味しない。
- 北米の画像平均角度差 −0.44° / −0.35°、多雨端の+0.21° / −9.60°は**旧集団平均または旧カテゴリーの記述**。新しいマッチング後の条件付き分布結果ではない。
- PR #144のS1 +0.4382°/100mmは**種間の現存空間関連**。同一種の導入後進化速度や新S2効果ではない。
