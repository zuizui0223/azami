# V4 GEB 第3.3節：気候アナログ下の頭花3形質の局所的な類似性（2026-10-29 固定）

**固定する肯定的結果：** 異なる経度帯に属するアザミ属の分類群では、**実際の観測地点の気候を似せた地点ペアにおいて、写真で測定した頭花の向き・花色彩度・2D輪郭縦横比の3次元的な距離が、同じ分類群内の形態を地点間で置換した帰無期待より小さい**。これは生態学的・観測的な環境条件付き表現型の対応（conditional phenotypic alignment）であり、**核系統樹上の独立な進化的収束・適応を証明したものではない**。

## 投稿論文の主張と固定規則

1. **本文3.1を変更しない。** 原S1で最暖四半期降水量BIO18×画像頭花角度β+0.045446843、Holm P0.00920635。1981–2010気候平均と画像鉛直の関係で、雨除け効果の実験結果ではない。
2. **本文3.2を変更しない。** 原S2で2種在来・導入域合計297,622元観測、128-test familyの導入域花色3関連はHolmを通過。**導入域でのみ有意＝導入後進化**とは言えない。
3. **本文3.3はH3c肯定結果に固定。** 平均気候中心・総ハイパーボリューム・通常の弱い形質間rではなく、**同じ気候を占める局所地点間での3形質同時の類似性**を主結果とする。全体の体積や単独形質幅が未支持だった事実も併記。
4. **空間については独立の感度分析として扱う。** 緯度・経度の固定効果を主モデルへ自動投入して環境と空間を因果分離したとはしない。S1地理項を含む既存結果はSIとして示し、5°セル等重み・地域除外等の地理標本依存性に注意。S2は原の5°セル均等重み・セルクラスタ標準誤差に加え、別途の空間ブロック感度で確認し、固定元結果を書き換えない。
5. 主張できないもの: **進化的収束の独立起源数、共通環境での機能適応、遺伝的な形質統合、因果的環境選択、根拠のない全世界への一般化**。元S1 80・S2 128 Holm test familyおよび第3.3節の新H3c familyは別々。
