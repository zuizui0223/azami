# 自生域アザミ頭花の共変動・表現型空間・環境・進化/機能 — Gate A→E 統合実行

**主質問：** 世界の自生域で、アザミ頭花の**向き・可視小花色・輪郭**は、同じ観察個体群の中でどのような組み合わせとして現れ、その**共変動の強さ、占有する分布密度・重なり、環境との対応**は種内と種間でどう異なるか。さらに、その組み合わせの進化史と送粉・食害機能のどこまでを別の実証系で支持できるか。

本設計は「形質ごとに別論文」でも「Gate Dだけ別研究」でもない。**一つの問い、一つの自生域ソース、一つの同一観察標本定義、段階的に拡張する推定対象**である。従来のGEB Chapter 1 V3（8段階、参照16数値ファイル）は固定した比較対象として残す。V4の新推定をV3の証明と混同しない。

## 現在の実行母集団

- 元の写真取得前メタデータ665,115観察・1,122,854写真から、形質を見る前にWCVP/地域条件で選んだ**313,350自生域観察／306受容分類群キー**。在来域判定は個別植物の自生由来を証明しない。
- 既存の頭花測定行あり：217,104観察。**主要9数値出力が同一観察で適格**：157,779観察／242受容分類群。向き1、色4（円環色相sin/cosは一体）、輪郭4なので**8構成概念、3主モジュール**。27登録項目を独立27形質とは数えない。未測定と生物学的ゼロは異なる。
- 原画像の重力向き、真正Labスペクトル、総苞片付着・棘の実長、粘液、送粉者実効性はこの観察表の測定変数に入っていない。フィールド・遺伝解析の結果に自動変換しない。
- 現行の5環境要因（BIO1/BIO4/BIO12/BIO15/RSDS）は、主解析の形質応答を見ずに固定した予測子セット。観測の分解は種平均（between）と同種内偏差（within）を区別する。

## Gate A→E（コード実行順と科学的役割）

| 順序 | コード／科学的推定対象 | 主な停止条件 |
|---|---|---|
| **A QC・標本** | `analysis/v4/native_observers.py` が既存の暗号化元メタデータから**人の投稿者IDと画像同定品質**を私有runner内で回収、`native_gates_ae.py` が同じ9測定の実交差・月・5°等面積セル・原撮影者の重複を集計 | 元写真/投稿者対応、ソースSHA、27形質QC、分類概念が不一致なら強制停止。元投稿者が無い場合B/C/Dの独立標本結果は公表しない |
| **B 共変動** | Gate Aで決めた同じ頭花記録から向き×色×輪郭の28構成概念ペアを**種内/種間**で比較。共分散、signed r、RV、等数種bootstrap；既存の環境係数で調整した同じ観察とも対照 | 生物学的独立個体ではない、n依存RVと画素誤差、20分類群未満は一般化停止 |
| **C 占有分布** | **同じGate A標本**からモジュールごとに90% KDE probability-content体積、密度積分の重なり `∫min(p,q)`、正確な同数実測W2、中心距離と中心除去W2を推定。50観察/種、共有座標/帯域、同種50+50有限標本基準 | 空間/撮影者・種内反復不足、画像輪郭と観点依存、異次元体積の直接順位づけ禁止 |
| **D 環境による形質分布再編** | PR #144の事前固定5環境変数モデル、空間診断、52代替配置、104条件付き共分散を維持。同一Gate A集合で、種の置換と**同種の低/高降水・日射勾配の中心移動/形状W2**を分離 | 分布片側しかない種の「種内変化」は識別不能。温度/降水・空間・撮影者を因果作用と同定しない |
| **E 系統・生物学的利益** | 種名と受容分類群の対応を厳密に照合。EAzamiの7分類群の歴史とaza3の独立した同一個体・送粉/形態測定を**別証拠として**重ね、どの機構を野外検証するか決める | 直接系統/種概念が曖昧なら系統推定停止。写真のRVを遺伝的レゴや送粉者選好の証拠に置換禁止 |

**同じデータの違う結果を混合しない**：Bで使う標本とCで使う標本、Dで同種の低/高比較に使う標本は、**Gate Aで原投稿者×種×空間セルの重複を制約した同じ候補集合**から選ぶ。B/Cは各分類群50観察の同数再抽出を使う。Dは同候補集合内で、全自生域の**種別気候中央値**を境界にし、同じ種が低高双方に独立セルを持つ場合だけ比較する。並行してPR #144の全件条件付き統計モデルは高精度の参照として保持するが、B/C小コホートと同一視しない。

## 実際に見つかった分類学的な破綻候補

既存の313,350観察の元学名→WCVPキー→樹端点の公開済み対応表（[PR #144の学名照合](../analysis/v4/results/20261020_native_phylogeny/taxon_mapping.json)）では、**7つの受容分類群キーが複数の異なる元学名を含む**。4キーは樹上でも曖昧、3キーは元名の一方だけが樹と対応していた。以下のようなデータ混合を「大きい種内分散」と誤認するおそれがある：

- `Cirsium brevicaule` と `C. irumtiense` がともにWCVP `206745753`。南西諸島で白/淡紅花を比べるEAzami/aza3研究の**独立分類群**を、統計解析で無検討に同一種として統合してはならない。
- ほかに *C. coryletorum* × *C. vlassovianum*, *C. hupehense* × *C. lineare*, *C. murdockii* × *C. tweedyi* は樹上曖昧。
- 残り3キーにも別々の元名をまとめていた例がある。樹端一致＝受容分類群概念が一意という保証ではない。

そこで共有A→Dの**分類感度**では混合した7キーを主計算から除外し、残る自生域の何観察／何分類群で推定できるかを公開する。元学名を保持して別集団へ戻せるかは別のauthority-backed追試であり、この計算では自動で種分割を作らない。EでEAzamiの変種・西表島の学名が正確に対応するかを**未解決/衝突として出す**。

## 二層の実証と限界

**第1層・全球画像フェノミクス（azami）：** 観察された頭花の形質分布と、空間・環境による共変動の**記述的パターン**を確定する。同じ写真から求めた色×形の相関に画素・撮影距離・向きの技術的共分散があり得る。種内の画像上の分散を生物学的遺伝分散としない。

**第2層・進化/機能実証（EAzami・aza3）：** 花色祖先状態とアントシアニン再活性化、総苞片開出・送粉接触、粘液/植食、防御、倍数化/交雑履歴は独立の核系統・同一植物実験で検証する。別々の原データを学名で機械結合して「同じ個体で見た」ことにはしない。

予測と反証可能性：

1. **色の分布の種間分離は形状と異なる**：歴史的旧PR92では色の中心除去W2が同種内基準を超える種対が輪郭より多かった。この差が新しい自生域・同じ標本・カメラQCでも残るかを見る（ただし旧PR92は別母集団なので新結果へ転写しない）。
2. **種間での提示×色の結合は全頭花部品に一律ではない**：PR #144既存matched共分散で正側区間が出た異種モジュールの候補を、セル×投稿者均等化・同数抽出と真の角度測定で見直す。失えば撮影/標本形成の見かけの可能性が高い。
3. **現在の環境と進化的組立起源を分ける**：環境条件下の形質セットが種分布上で偏っていても、それは色素再発現、送粉者利益、共通の進化的起源を証明しない。EAzamiの核系統＋aza3の操作実験で検証する。

## 実行インターフェースと保存境界

既存 `.github/workflows/v4-native-integration.yml` が**唯一の一次自生域Actions**。認証済み元メタデータ→環境decode→Gate A QC→既存環境モデルと共変動・空間診断→**同じ元表からB/C/D/E一括追加診断**の順で実行する。

```bash
python -m analysis.v4.run_native_abcde \
  --table PRIVATE/observations.csv.gz \
  --receipt PRIVATE/measurement_receipt.json \
  --models work/native-integration/output/native_trait_models.json \
  --integration work/native-integration/output/native_integration.json \
  --spatial work/native-integration/output/native_spatial.json \
  --mapping analysis/v4/results/20261020_native_phylogeny/taxon_mapping.json \
  --observers PRIVATE/native-original-observers.csv.gz \
  --output work/native-integration/output \
  --b-bootstrap 200 --c-replicates 12
```

今の12反復は**計算パイロット**であり、PR92と同じ30反復やKDE帯域感度、同一種finite-n基準、地域保留を満たす投稿用確証ではない。結果を見てから事後的に選択を変えて「予測通り」とすることは禁止。元写真、元座標、個票、原投稿者ID、復号鍵はActions artifactに含めない。公開するのは出所SHAと集計JSONのみ。

**成果物：** `work/native-integration/output/unified_gate_abcde.json`。各ゲートに`status`、共通母集団・必要な変数・停止要因・予測と反証可能性を併記。数値ゲートが動いても機能実証が未完了のため**A-Eの全生物学的妥当性にPASSは付けない**。
