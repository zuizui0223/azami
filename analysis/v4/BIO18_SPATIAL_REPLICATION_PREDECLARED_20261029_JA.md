# BIO18と頭花画像角度：地理的反復性の感度検証仕様（2026-10-29）

## 科学的な問い

「降水量が多い地域ほどアザミの頭花は下向きに写る」という全球の分類群間の関連が、**日本・北米など異なる放散史を持つ分類群の地域的入れ替わり**だけに由来するのか、**複数の地理区分の内部でも観察される**のかを調べる。これにより、弱い画像形質間rを無理に機能解釈するのではなく、現在のGEB論文の一番強い生態学的結果を検証する。

## 既知の独立した先行診断

- 10月22日の実測 `analysis/v4/results/20261022_S1_RAIN_SPATIAL_GEOGRAPHY_RESULT_JA.md`：**年降水量BIO12**・BIO1/BIO4/BIO15/RSDSの5変数・170,066角度画像/244受容分類キーを元とする別解析。分類群集約と経度帯/球面2次空間項を追加すると、BIO12の正の勾配の大半はゼロを含む。地域構成が関与しうることを示した。
- 現在のGEB V4は **最暖四半期の月平均降水量BIO18**・BIO05/RSDS/標高の4変数・**168,907適格観測/178分類群**で、分類群間標準化β=+0.045446843、元の**S1全80検定**のHolm P=0.0092063506。
- 上の2つは**降水変数・予測変数・適格数・母集団と推定モデルが異なる**。BIO12の空間調整結果をBIO18の実証・反証として流用しない。

## 実施する一つの主検証

コード：`analysis/v4/s1_bio18_geographic_replication.py`、GitHub Actions：`.github/workflows/v4-s1-bio18-geographic-replication.yml`。

1. 既存の秘密鍵付きオリジナルS1観測暗号文をGitHub Actions内部だけでSHA256検証・復号し、元画素CHELSA/WorldClimの7変数をS1のみに再取得。元12気候値と形質QC・分類群5観測以上の**同一コホート168,907件/178分類群**を厳格に復元。
2. BIO18/BIO05/RSDS/標高・分類群ごと等重み・分類群クラスタロバストWLSで**元のβを再計算**。βの不一致時は感度結果を公開しない。
3. 同じ個票から分類群平均の角度・気候・地理を求め、**地理なし、あらかじめ定めた3経度帯の構成比、球面2次8基底**の3モデルを並べる。新しい地理項は感度分析であり、元80検定の再Holmではない。
4. 撮影枚数の集中に対し、元写真平均と種内5°セル均等平均との差を確認。両方について事前に決めた3経度帯の**内部回帰と各1帯除外**を算出する。3経度帯は旧BIO12診断と同一だが、生物地理区でも独立な系統放散でもない。
5. 出力は**集計係数・HC3の点別95%区間・分類群数・元ラスタ取得SHA**のみ。撮影者・写真ID・分類群ID・精密座標は外へ出さない。

## 対立する解釈と判定

- **地域調整と複数地域内で正方向が比較的維持される場合：** 全世界の種構成だけでは説明し切れない気候―形態関連の候補となる。ただし写真の見かけ角度と系統依存・局所適応の区別は残る。
- **地域調整や1地域除外で大きく縮小・方向反転する場合：** 「どの地域でも降水量に応じて下向き」という一般則より、**地理的に異なる分類群の形態構成と気候の共分布**が研究対象となる。全球の元関連は残るが、独立した雨よけ機構の主張は一段抑える。
- **地域内で推定不能、または区間が幅広い場合：** 新しい証拠が足りないことを結果として残し、一般化と地理の切り分けを未解決とする。
- どの場合も**画像鉛直≠重力、BIO18気候値≠観察時の降雨、観測相関≠適応**。元のS1 80検定・S2 128検定、Holm4件、全28ペアSIは上書きしない。複数感度モデルを独立な確証的P値として合算しない。
