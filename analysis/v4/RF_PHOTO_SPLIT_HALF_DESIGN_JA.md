# 原S1写真の独立二分法による地理的形質シグナル再現性（2026-11-01）

**位置づけ:** V4 RFの予測Skillが負となった理由を切り分けるための、新たな**探索的・写真QC診断**。既存のGEB原稿、2026-10-24凍結S1 80検定/S2 128検定、H3c、12→21→23→28→34 RF推定を変更しない。元の写真間/格子間RMSE比は再現性やICCではないため、本分析を独立に実施する。

## 事前固定の設計

- 入力: SHA256/AES-GCM認証済み原S1 **313,350観測**。機密原本・観測ID・場所・分類群名は保護GitHub Actionsの内部から出さない。追加ラスタ不要。
- 形質: angle、L*、chroma、joint hue（sin/cos）、aspect、circularity、solidity、width profile CVの8構成。各形質の `__eligible`、座標、欠測を個別判定。
- 地理: **1° / 5°** を別集団として解析。元の原S1写真QC集団であり、28/34環境完全ケースやGEBの178分類群と同じ分母ではない。
- 分割: 原 `obs_id` を固定した3つのSHA256 seed（20261101、20261103、20261105）で、**分類群×地理セル内**の写真をランダム順に並べ、交互にA/Bへ配置する。写真の形質値や撮影場所の詳細は分割キーに使わない。同じ観測IDが両側に入らない。
- 格子ごとの条件: **A/Bそれぞれ3写真以上**（全体で最低6）。分類群は対応する格子が8個以上、全写真40件以上。A/Bの同じ地理セルだけを突き合わせる。色相はsin/cosの単位ベクトルを扱い、それぞれの半群中央値ノルムが0.2未満のセルを除く。
- 主要アウトカム: 分類群ごとにA/Bから計算した地理セル中央値について、**分類群内中心化した空間パターンの一致度**（多変量の正規化内積、1変量ならPearson相関に対応、範囲−1～1）を算出。1変量ではSpearman順位相関も併記。色相は角度差ではなくjoint unit sin/cosで比較する。
- 副次アウトカム: A/Bセル中央値間RMSE、A/B平均のセル間RMSE、それらの比、分類群の一致度が正・0.5以上となる割合。各分類群を等重みとする5/50/95分位点、分類群再抽出500回の中央値範囲（記述的95%）、分類群内でB側セルを置換した199回の帰無中央値分布を匿名集計する。3 seedで方向が保たれるか確認する。帰無分布は探索的キャリブレーションで、新たな確認的P値群ではない。

## 判定の順序と留保

1. **先に分母**: 形質・粒度・seed別に、適格分類群・セル・写真数が十分かを監査する。不十分なら空の「肯定結果」を出さない。
2. **次に再現性**: 3分割で一致度中央値、分布、記述的bootstrap範囲、空間セル対応を壊した帰無分布を比較。弱い場合は気候変数追加より写真測定・反復・撮影機会のQCを優先する。
3. **解釈境界**: 再現しても、独立個体・直接的測定誤差・集団遺伝・適応・因果・RF外挿性能の証明ではない。撮影者・時季・同じ株の別観測を完全に排除できない。格子の中の局所環境不均一性も残る。分類群間の異なる写真機会・観測個体の重複・系統は未調整。
4. **論文境界**: 新しい結果を確認的なGEB S1/S2/H3cへ加算しない。元原稿と数値を変えない。
