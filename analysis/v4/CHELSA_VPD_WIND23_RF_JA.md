# PR #167：CHELSA BIO21 + 大気需要・地表風 2変数（計23）

## 目的・位置づけ

前段の**12→21変数の実測RF**では、未知分類群で8構成形質のうち7形質、未知3経度セクターで8/8形質が訓練fold平均より悪いSkillだった。これは新しい分野の独立データを検証する動機にはなるが、探索的RFによる花形質の気候関連・適応の否定ではない。

元のS1暗号化・SHA認証済み313,350行の9つの歴史的CHELSA環境列には、VPD（`chelsa_vpd_mean`）と地表風速（`chelsa_sfcwind_mean`）が**既に存在する**。新たな土壌・植生取得の前にこの2列を、既にCHELSA 21変数を抽出した同じ元観測に追加して、21対23のRFにする。**CHELSA原本に含まれる変数であって、TerraClimate5変数／風2変数の取得済み証拠ではない。** 44候補の既存登録・順番は変更しない別枠の追加比較とする。

## 遮断条件・評価方法

- 元S1のoriginal解読receiptと各元ラスタのSHA/scale/offsetを、リポジトリで固定済みの`analysis/v4/environment_source_metadata.json`へ照合し、不一致を拒否する。今回新しい風/VPDラスタをダウンロード・再推定しない。
- `chelsa_vpd_mean`と`chelsa_sfcwind_mean`の**実際の欠測を保持**。どちらかの値がない行は21側からも除外して、公平な21対23を実施する。温度や季節性の存在から穴埋めしない。
- 8構成形質（画像角度、明度、彩度、色相sin/cos共同、aspect、circularity、solidity、widthCV）に同じ個票QCと5°セル中央値を使う。初回はセルあたり3枚以上・分類群40写真/8セル以上、unseen taxa GroupKFold・3セクター除外。
- **別ラベルの事後感度**として、向き・彩度・aspectに限りセル≥1写真と分類群数均等group-foldを評価する。12→21とは同じ絶対Skillを直接比較せず、**各ペア内部の21と23を同一cohortで比較**する。
- 層ごとの予測重要度は**訓練外の置換損失**で見る。VPD/windは原因・花温・花柄力学・送粉者相を直接測っておらず、これは機構や適応の因果テストではない。
- 権限あるGitHub Actions環境でのみソース復元・RFを行い、集約JSONだけを公開。写真ID・種ID・正確な座標・撮影者・個票予測・元ラスタはアップロードしない。

**判定:** 21→23の外挿Skillが訓練平均を上回るか、単なるlossの縮小なのかを区別し、厳格コホートと事後感度の双方を並記する。原GEB本文、既存Holm係数・図表・H3cは一切変更しない。
