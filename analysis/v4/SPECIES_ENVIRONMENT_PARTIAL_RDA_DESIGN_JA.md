# V4元S1：気候22変数×全8形質の部分RDA・空間変動分割（2026-11-07）

## 研究課題と位置づけ

V4（元自生域S1、313,350元観察）で得られた**173分類群のsPLS2共通写真集合**を、環境（気候）と撮影地点の空間構造に分けて記述する。sPLS2で温度・日射軸と降水軸を探索した後の事後分析であり、独立の確認的検定ではない。これまでのRF・GEB本稿S1/S2・H3cの係数や検定は不変。

**最重要の制約：今回の主推定は気候［C］×空間［S］の2ブロックである。系統［P］を加えた3ブロック変動分割は未実装・未推定。** V4に厳密対応した、出所認証済み・樹端名対応済みの系統樹が現在の元データ経路にない。旧V2の52本の歴史的配置樹成果物は本解析のV4原分類群との対応を証明しておらず、旧の木を無言で代入しない。系統補正後の気候固有寄与・系統固有寄与は主張しない。

## 入力・分類群対応

- 既存 `species_environment_existing_inputs.load_existing_inputs` を通し、復号済みV4元S1、検証済み元7気候・外部7・追加9変数（23軸）と原本/抽出SHA記録を照合。新たなラスタ取得はしない。
- 全8形質（向き1・花色3・輪郭4）が**同じ写真で全て適格**な写真だけを使う。1分類群に適格写真最低5枚。元sPLS2の `aggregate_species_joint` を再利用し、花色の円周色相sin/cosは単位ベクトル平均後に方向化。Y列は9次元だが、色相2次元全体の標準化分散を「1形質」として重み付けする。
- 空間基底は、同じQC写真の元位置で球面座標の1次・2次、計8項を計算し、写真ベースの種平均にする。先に描いた8項は固定し、形質を見て空間基底を選ばない。これは分布範囲の真の重心や撮影者補正ではない。
- 同じ分類群で22気候変数が有限なものだけを主解析・4/8/22軸感度に共通使用（入力の22気候の欠損は黙って補完しない）。分類群数、共通写真数、3経度帯の支持数を匿名報告する。

## 推定設計（探索的）

**主解析**：環境22軸を形質を見ずに分類群平均でz化→PCA→上位6軸を使用（PCA自体の寄与割合と全22候補の軸負荷も保存）。共変量空間：固定球面8項（z化）。同じ分類群に対して以下を通常の線形多応答RDA／OLSで適合する。

- `Y ~ C`（気候ブロック）、`Y ~ S`（空間ブロック）、`Y ~ C + S`（共同）。切片・調整済みR²を計算する。
- 気候固有 = adjR²(C+S) − adjR²(S)、空間固有 = adjR²(C+S) − adjR²(C)、共有 = adjR²(C)+adjR²(S)−adjR²(C+S)、未説明 = 1−adjR²(C+S)。調整済み寄与は負になり得るため0へ丸めない。**気候固有とはこの空間8基底に条件づけた寄与**であって全地理・系統非独立性が消えたことではない。
- 主解析6気候PCのほか**4PC、8PC、元22軸**でも同じ分類群で実行し、軸数に対する感度を保存。元22軸は多重共線性を含むため感度であり、事後的に最高の効果を選んで主効果としない。
- 多変量応答は、全8形質共同（9Y列、色相の2列合計分散=1）のほか、花色・画像向き・輪郭各サブモジュールをそれぞれ並行して報告。1分類群=1解析単位とし、観測数の多い分類群は別途加重しない。
- 気候追加の探索的擬似F値についてFreedman–Lane残差置換を499回。全分類群置換と、元観測位置の3経度帯内置換を併記。経度帯内の残差にも空間相関が残り得るため、**いずれも完全に交換可能性が成立する保証はなく、確認的p値としない**。別途系統・撮影者・空間ブロック不確実性が未考慮。これらの擬似Pを既存S1/S2 HolmまたはsPLS2の固定結果へ混ぜない。

## 解釈の判定

1. 気候の調整済み固有寄与が大きく、4/6/8PC感度でも同じなら、**この空間8項を超える種間の気候共変動候補**と表現する。
2. 気候の固有寄与が0付近・負なら、sPLS2で見えた温度・降水軸が**種構成・空間と重なっている**可能性を明記する。負の調整済み寄与は気候に反応しないという証明ではない。
3. 花色・向き・輪郭で異なる場合は、**形質群ごとに気候との結びつき方が異なる**探索的現象として報告。ただし画像構成と撮影条件のバイアスに注意。
4. 本解析は予測力を測るRF/sPLS2と異なり、同じデータの変動分割を行う。**地域外で予測が不成功だった事実は変更されない。** 系統独立性、環境因果、雨よけ適応、色素経路、重力下垂は証明できない。
