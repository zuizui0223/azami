# V4：標高を外した気候のみモデルの厳密比較（2026-10-31）

## 結論と主線

現行GEB本文のS1/S2主解析は、2026-10-24に **BIO18＋BIO05＋RSDS＋標高** の4変数で凍結された。本稿では**凍結済みのHolm検定結果や本文を変更しない**。科学的問い「気候条件と写真頭花形質はどこまで関連するか」に対して標高は地形的な代理変数であり、気候と共線的な成分を含む。**標高なしの3変数モデル**を、同一標本・同一写真・同一重みで追加解析して比較する。

- **M3 気候のみ:** CHELSA BIO18（最暖四半期の月平均降水量）、BIO05（最暖月最高気温）、RSDS（短波日射）。
- **M4 元の凍結済みモデル:** 同じ3変数＋WorldClim標高。**M4の元係数を厳密再現できない場合、M3の結果を採用しない。**
- 共通の12環境が揃った写真から元の形質QCを適用し、**標高だけ除くことによって新しい写真を母集団に加えない**。結果表にS1とS2の資格数を別々に示す。
- S1：分類群間・分類群内係数、分類群等重み、分類群クラスタSE。元の **168,907写真記録／178分類群**、M4のBIO18間係数 **+0.045446843** を再現する。
- S2：*C. arvense* と *C. vulgare* それぞれ在来／導入の4層。花色の元6比較の元データ数とM4係数を再現してから、M3で **BIO18・BIO05・RSDS** の係数、95%点別区間、AIC、VIF、標高の増分説明を記録する。撮影者×5°セル重複調整、同一月・年項、セルクラスタ誤差を維持する。
- H3c（現行Results 3.3）は**もともと標高なし**のBIO12＋BIO01＋RSDSで気候が類似する地点を比較しており、変更しない。

## 既に取得・照合できた実データ：旧探索的11モデル

過去の認証済み成功実行 [Actions 40058244725](https://github.com/zuizui0223/azami/actions/runs/40058244725)、artifact `12546296962` の元ZIP SHA-256：
`30d2e9537f470f7925372f16f166ca2ea941ae8e93c35f28ea716f7ad1b30ce5`。
これは**今回作る厳密M3（BIO05版）とは異なる探索的モデル**である。

1. 同一156,683写真・174分類群の共通形質セットで、BIO18＋BIO01＋RSDS＋BIO04＋BIO15 に標高を追加候補とした探索は、VIF>5により標高を自動除外した。したがってこの探索での `warmest_quarter_BIO18` と `warmest_quarter_BIO18_elevation` の**実際の推定は完全に同一**。この5変数気候モデルの画像角度×BIO18分類群間 β=+0.053058258、未補正P=0.00003221。**現行S1 168,907/178の元Holm結果とは母集団も共変量も違う**。
2. 既存S2探索のBIO18＋BIO01＋RSDSは標高を含まない。これに標高を加えると、*C. arvense* 導入域の元ソースVIF（標高）が6.34となり、**同群の9数値形質成分で標高追加モデルは共線性基準未達**。
3. 他の3分布群ではBIO01ベースの標高あり／なしが27成分で同一コホートで推定でき、**そのうち25で標高ありのAICが２以上小さかった**。これは標高が残余の関連情報を担う可能性を示すが、AICは適応の証拠でも独立な交差検証でもない。
4. 特に *C. vulgare* 彩度は、導入域で標高ありのAICが141.62小さく、在来域では13.23小さい（同一写真・BIO01ベース、探索的）。**標高なしが自動的に優れたモデルとは断定できない。**

## 新しい厳密比較の評価基準（結果に合わせて変更しない）

- M4の元ソース **S1 BIO18 β=+0.045446843、S2元６係数／対象数** が誤差 `3e-7` 内で再現されること。
- 3変数と4変数で、各形質の写真記録・分類群・空間セル・撮影日・回帰重みを**完全に揃える**。VIFはM3/M4双方で記録し、特定の形質のP値による変数選択は行わない。
- 比較指標：気候３変数の符号・標準化係数、点別95%CI、M3−M4 AIC、標高追加による重み付き残差平方和の減少率。AICの改善は適合度であり、因果機構や予測一般化を証明しない。
- **元のS1=80件、S2=128件のHolm補正をM3に流用しない。** M3は2026-10-31に追加した探索的感度分析とし、Pは未補正で提示する。
- もしM3で降水係数が維持されても、既存の地理調整・東側分類群除外での減衰は残る。気候と地理の因果分離とは主張しない。
- *C. arvense* の「導入域で標高が高いほど暗色」の元のM4結果は、M3には標高の係数自体が存在しないため、M3で再確認できない。代わりに気温・日射と明度が関連するか、**同じ母集団の気候効果を調べる**。
