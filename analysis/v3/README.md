# Chapter 1 v3 reviewer-response diagnostics

The **canonical Chapter 1 analysis remains the frozen v2 analysis described in the repository root `README.md` and `reproducibility/README.md`**. Nothing in this directory replaces that analysis line, its frozen outputs, its public release contract, or its manuscript-level primary result set.

## Canonical analysis

Use the immutable frozen v2 code/input route documented at the repository root:

- frozen primary cohort: 46,276 strict-spatial observations / 259 taxa;
- frozen v2 ecological scripts and contracts;
- frozen environment atlas, sampling-composition, spatial and historical sensitivity outputs;
- frozen public reproduction bundle and validation gates.

The root `README.md` is the authoritative entry point for reproduction and interpretation of Chapter 1 v2.

## Purpose of this directory

`analysis/v3/` contains **reviewer-response, provenance and post-hoc diagnostic work only**. It may be used to understand specific limitations raised during revision, but it is not a new canonical ecological pipeline.

Permitted uses include:

- source/provenance reconciliation;
- checking historically measured fields that were omitted from an older aggregation;
- collinearity diagnostics and VIF-based sensitivity analyses;
- bounded measurement-stability diagnostics;
- manuscript claim-boundary checks.

## Explicitly noncanonical analyses

The following results are preserved for audit but must not replace the frozen v2 primary analysis or be promoted to the manuscript's main result set solely because they were produced later:

- the restored all-27-endpoint rerun of the v2 atlas;
- VIFstep-selected multivariable all-trait scans;
- alternative post-hoc multiplicity families generated by those scans;
- any endpoint recovered after the frozen v2 analysis family had already been inspected;
- new image remeasurement, calibration, hypervolume or expanded-cohort experiments.

These analyses can support statements such as "the result was examined under an additional sensitivity analysis". They cannot retroactively redefine the preregistered/frozen v2 family or turn exploratory associations into independent causal effects.

## Revision principle

**Keep the original frozen v2 analysis as the scientific spine. Use v3 only to answer reviewer questions, clarify limitations and test whether a v2 interpretation needs to be weakened.**
