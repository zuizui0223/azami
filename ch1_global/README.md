# ch1_global

`v2/` is the frozen executed implementation layer for the Chapter 1 global continuous image-phenomics submission. Exact numbered script paths are retained because workflows and artifact provenance cite them.

New users must start from `analysis/ch1/` rather than selecting a numbered script directly. Historical planning documents and `v1/` are not part of the submission-facing path and can be removed from the active branch once the cleanup regression checks pass.
