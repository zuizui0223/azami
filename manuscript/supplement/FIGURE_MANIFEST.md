# Supplement figure provenance manifest

The repository assets named Figures S1–S5 are submitted as Figures S1.1–S1.5 in Appendix S1. They are deterministic release products generated by `analysis/build_supplement_figures.py`. Figure generation does not re-estimate any biological model or alter any manuscript claim. Git stores the complete numeric inputs and generator; CI regenerates SVG/PNG/PDF release outputs, verifies their SHA-256 values, and packages them as a submission artifact.

## Frozen inputs

- **Figure S1**: `manuscript/supplement/figure_data/FigureS1_nested_variance.csv`, copied from the frozen nested-visible-variance result family.
- **Figure S2**: `FigureS2_primary_coefficients.csv`, recovered from GitHub Actions artifact `8330350031` (`table_s1_all_global_coefficients.csv`). The source contains 28 linear rows plus four joint circular-hue rows; the generator expands hue sine/cosine to recover the complete 36-component coefficient grid. BH-supported cells are marked from `tables/S03_primary_within_taxon_BH_supported_rows.csv`; hue sine and cosine remain separate computational components.
- **Figure S3**: `FigureS3_spde_model_group_summary.csv`, recovered from workflow run `29339137476`, artifact `8313574392`, artifact digest `sha256:b877713456360144106d7531fddf95ac8c3c82fa1597d0cd3cbc4c9149a53cf5`.
- **Figures S4–S5**: `FigureS45_spatial_robustness.csv`, copied from the frozen spatial robustness audit (`S09_spatial_robustness.csv`; source workflow run `31152400475`, artifact `8983877726`, digest `sha256:151161f926dbc92d35832a0bd71622e4f1f3018c9047a7ba8b4ad94926273dca`).

## Figure meanings

1. **Figure S1.1 — nested visible-variance sensitivities.** Below-assigned-taxon visible-variance fractions for the full nested decomposition, one-head-per-photo sensitivity and balanced 10-photo sensitivity.
2. **Figure S1.2 — complete primary climate coefficient map.** All 9 endpoints × 4 CHELSA predictors are displayed. Asterisks mark the eight component rows with BH q < 0.05. Hue sine and cosine require joint circular interpretation.
3. **Figure S1.3 — grouped SPDE-INLA model comparison.** ΔWAIC is calculated within endpoint across climate, climate + topography, climate + soil and full predictor groups; zero is the best fitting group within that endpoint. This is a model-fit comparison, not a significance map.
4. **Figure S1.4 — residual spatial autocorrelation.** Residual Moran's I from diagnostic refits of the lowest-WAIC SPDE specification; 999 permutations were used and no endpoint had P < 0.05.
5. **Figure S1.5 — broad-region omission stability.** Minimum taxon-rank stability under broad-region omission for each endpoint.

The withdrawn lability quadrant graphic is not part of the submission figure set.

Figure S1.9 is generated by `analysis/build_ch1_interpretive_figures_v3.py`
from `tables/S03_primary_within_taxon_BH_supported_rows.csv` and
`tables/S08_randomized_PGLS_retained_rows.csv`. It is the former main Figure 6,
demoted because direct-backbone coverage is 54/216, retained Pagel-λ estimates
are zero and direct-backbone non-circular phylogenetic signal is unsupported.
Its replacement rendered release remains pending.

## Reproducibility check

The final generator was executed twice from the same frozen inputs in the same pinned software environment. All 15 SVG/PNG/PDF outputs were bitwise identical between the two executions. SVG IDs use a fixed Matplotlib `svg.hashsalt`; PDF creation/modification timestamps are suppressed; stable output metadata is used for release hashing.
