# Reproducibility artifacts

This directory contains generated scientific artifacts that are intentionally versioned because they are part of the reproducibility record, not manuscript files.

## `figures/`

Frozen Main and Supporting result figures plus the compact source/provenance files needed by the figure builders. The files were moved here from the former manuscript-facing layout without changing their scientific content.

## `contracts/`

Compact trait-definition material required to reconstruct the image-measurement and analysis contracts.

Canonical numerical outputs remain in `analysis_outputs/`. Manuscript prose and journal submission packages are kept outside this repository.
