## 2. 一つの主線、三つの統計的に異なる応答

中心質問を以下の三つに分ける。「機能」は現時点で**候補機能**。実測した画像表現型に「機能的多様性」という確定名を使わない。

**Q1：共変動（integration / covariance architecture）**

- 同じ観察上の向き・可視花色・輪郭の相関／共分散の**組み合わせと方向**は何か。
- 同じ分類群内の場所間（within）と受容分類群の平均間（among）ではその構造は異なるか。
- 形質ペア間で差は均等なのか、それとも「色×形状」「向き×色」「向き×形状」などが別方向へ変わるのか。
- 見かけの共変動が、同じ画像の画素・撮影角度・共通の頭花検出誤差から生じた可能性を保留する。

**Q2：占有分布（trait probability distribution / disparity）**

- 同じ中心をもつ分類群でも、分布の幅・歪み・密度・重なり・組み合わせ制約は違うか。
- 密度の重複とWasserstein距離を**中心移動**と**中心を除いた分布形状差**に分ける。
- 相関が強いと高次元体積は縮小し得るため、**共変動の強度 ≠ 密度で占める空間の広さ**。広がり一数値では多様性を代表させない。

**Q3：環境（environmental structuring / scale）**

- 気候・日射・水分に沿って、(a)分布中心、(b)種内の分布幅、(c)種内／種間の相関構造、(d)分類群間の分布重複がどう変わるか。
- **同種が複数環境に出現した中での変化**と、**異なる種の入れ替わりによる変化**を分離する。
- 現存形質の気候との相関を選択・可塑性・機能・祖先環境の証拠にしない。

- 形質独立に凍結された自生域名簿へ、既存の写真測定と環境を左結合する。

### Gate B — 共変動の主解析（体積より先）

- 一次サンプルは同一観察3モジュールを同時測定した集合。各モジュールは試験前に固定した代表座標で扱い、入力尺度は分類群を等重みした共通基準で変換する。
- 始点として既存の手動 `native_space_gate.py` が画像向き・彩度・輪郭長幅比という**3座標**を検査する。ただしこれは**簡易プリフライト**であり、他の色次元・輪郭次元の機能的空間を代表したことにはならない。
- 同じ標本範囲で**種内W、種間B、全T=W+B**を分け、変数ペアの符号付き相関／共分散、RV、尺度別行列の方向・固有構造を記録する。
- 既存V3のQAP・ブートストラップとの橋を架ける際は、**同じ測定集合・同じ重み・同じ尺度**に加えて**同数の行への再抽出とスケール別RV帰無値補正**を行う。V3の補正前33/36という組数を頑健な件数と呼ばず、共通42分類群の比較結果を自生域177分類群以上へ移植しない。
- 追加の帰無対照では、各単一形質の周辺分布を保ったうえで**同時出現する組み合わせ**をずらす。撮影者・分類群・地域セルの構造を壊す無差別な写真シャッフルはしない。
- **採否指標：** 共変動の符号と強さ、標本調整区間、主要撮影者・多記録分類群の除外、同一環境条件での比較、空間的な外部妥当性。単に低P値を探さない。

### Gate C — 密度分布・重なり（旧PR #92を再利用）

旧PR #92の実行済み手法を**新しい自生域母集団・適格集合の下で使えるか**を判定する。生物学的意味の異なるモジュールを最初から強制統合しない。

- **単一モジュールから**：向き1D、色の円環性を守った共有2–3D表現、輪郭の共有2–3D表現。全分類群で同じ座標・中心・スケール・平滑化を用い、選び方を気候相関で決めない。
- 適格分類群に対して、旧PR #92の**50観察・30回の同数抽出**を初期比較用の既知仕様とする。元の50は普遍的な充分性条件ではないので、分類群×地理セル・撮影者の独立数とサンプルサイズ感度で再審査する。
- **相補的指標を別々に出す**：(1)90% KDE probability-content体積（単位は共有投影空間）、(2)TPD密度重複 `∫ min(p,q)`、(3)同数点からのWasserstein W2、(4)中心距離、(5)中心を除くW2。**体積差・重複・中心差を同一視しない**。
- 同種から分割した50+50観察による距離基準、0.75／1／1.25帯域感度、同一環境で分類群ごとの標本数差の影響を点検する。旧PR #92では高い帯域順位相関にもかかわらず絶対重複率が変わり、輪郭の中心差除去後W2が大きいというだけでは大半の種間ペアが同種内基準を超えなかった。
- 多次元「頭花全体」のKDEは**同一観察で全主モジュールが揃い、有効次元に対して標本と独立地点が十分**な場合だけ許可する。旧PR #92の総苞6分類群・全頭花5分類群のPCA投影（保持分散63.6%／42.8%）は生態学的な高次元体積の根拠にしない。
- 既存の相関楕円体（旧PR #92、厳しい条件で種間／種内体積比0.069、緩い条件では0.491）は**密度ハイパーボリュームとは別物**として明示。分布の広がりは、形質分散と共分散の方向の両方に依存する。

### Gate D — 気候・地理との対応（同一推定対象を守る）

環境効果によって事後的に形質・分類群・基底を選ばない。登録済みのCHELSA予測子と6環境ブロックを背景として保持し、始点として**年降水量BIO12・日射RSDS**を既存の事前候補軸とする。ここでの生態的問いは一つの勾配の「独立原因」ではなく**共変動と空間の形状が勾配によって異なるか**。

- **種内効果**：同種が低／高環境に十分な独立セルで存在する場合だけ、その種内の平均座標・分散・共分散・密度分布を比較する。種が片側にしか存在しない場合、種内変化は**識別不能**。
- **種間効果**：環境に沿って分類群の構成が変わるパターンは別に報告。同じ分類群重み・種集合を固定する感度比較なしに「同じ種の形が変化」とは呼ばない。
- **分布の変化**を中心の移動、幅の変化、相関の回転、密度重複の変化に分離。ハイパーボリュームの単一回帰だけで済ませない。
- **環境幅×表現型幅**は旧PR #92の探索的問いを受け継ぐ。ただし地理分布の広さ・撮影地点数・種の豊富さによる自明な関係を同時に点検。分布幅と環境への適応可能性を同義にしない。
- 局所／地域保留で、単純な分類群平均・空間だけの参照より予測が改善するかを別に点検。予測改善がない場合は「記述的な対応はあるが一般化は未確定」。無理に新たな説明変数を足さない。

### Gate E — 東アジア史／機能への接続（独立した検証）

| 所有リポ | 接続する問い | 現在の証拠境界 |
| --- | --- | --- |
| [azami](https://github.com/zuizui0223/azami) | 全球の自生域で、**観測された頭花の形質空間**と共変動・環境がどう対応するか | 写真表現型。統合は機能または遺伝的制約の証明ではない |
| [EAzami](https://github.com/zuizui0223/EAzami) | その組み合わせが**同じ進化史で生じたか、異なる頭花部分が別々に変化したか** | 7分類群直接測定PCAのPC1=51.9%。日本放散では向き4–6、総苞片姿勢3、粘着性5の最低変化、3組中0組で堅牢な共通遷移局在。形質・進化樹・環境の重複は限定的 |

横断結合は**名称の単純一致は禁止**。WCVP受容分類群と日本38概念（変種・亜種を含む）を明示的に照合し、個体・写真・標本・核ゲノム・送粉実験は別々の証拠単位として保持する。既存日本38は14概念で正確な色形質照合、うち厳密な10観察以上は5概念という旧監査があり、この欠損を受容種名への自動代入で埋めない。

**接続の成果物**は観測されたモジュールの共変動と重複の地図、歴史的な反復・非同期性との**反証可能な予測**、そして同一個体で機能を試す対象形質の優先順位。全球の写真データを直接「適応的機能ハイパーボリューム」へ変換しない。

## 5. この再設計が避ける失敗

1. **強いRVだから大きな体積、または遺伝的モジュールとする誤り。** 相関行列の縮小／回転と占有分布の体積は別の応答。
2. **共通測定可能な少数分類群だけを「全球の頭花多様性」と呼ぶ誤り。** Gate Aで共通コホートと母集団の差を公開する。
3. **撮影枚数・観察回数を生物個体の豊富さと呼ぶ誤り。** 種・地域・撮影者を均等化する。
4. **写真の光沢を粘液、輪郭突出を棘の実長、EXIF鉛直を重力角度と解釈する誤り。** 機能的仮説は別証拠。
5. **旧labilityの精度交絡を再導入する誤り。** 過去の撤回済み指標・四象限を目的変数に採用しない。
6. **環境相関から歴史的な起源や自然選択を断言する誤り。** EAzamiでは現時点の生態的対応と起源時の環境が一致しない例がある。
7. **解析のたびに新たなワークフロー／PR／環境変数を増やす誤り。** 既存入出力に対する順番と停止条件を先に決める。

### EAzami・aza3最新結果の接続上限（10月20日時点）

- [EAzami PR #122](https://github.com/zuizui0223/EAzami/pull/122) は、Azamiで観測した種内・種間で異なる形質共分散を再現できる生成モデルを比較した。15,000回の事前設定シミュレーションで複数の構造が暫定的適格となったが、**未マージ・独立した保留検証は未完**。観測共分散から「遺伝的LEGOが成立した」と言い換えない。新しいazami主線では生成モデル群を増やさず、まず実際の共分散と写真誤差を識別する。
- [aza3 PR #61](https://github.com/zuizui0223/aza3/pull/61) の出典固定された *Cirsium arvense* 2022年実験の再解析は、共通36ブロックで送粉者除外−通常対照の可稔痩果割合差が **−0.5231（36/36ブロックで負）**。**これは送粉者依存の繁殖効果**であり、頭花向き・総苞片・花色そのものの操作効果ではない。種内の写真共変動をそのまま送粉者利益へ変換しない。
- [aza3 PR #64](https://github.com/zuizui0223/aza3/pull/64) は**未マージ**で、北米アザミ63樹端の著者定義「ハチドリ型7／昆虫型56」に対し外側総苞片開出が **6/7対10/56** と関連するという実測形態の予備結果を報告。ただし訪花型の著者ラベルには花色・形態シンドロームが既に含まれ得る。**独立の訪花・花粉輸送、系統・分布・写真の形態測定とは別層**で検証する。現在は形態×相互作用相手の候補であって適応の支持ではない。
- この3系列を接続する実証上の境界は、(1) azamiの自生域写真表現型、(2) EAzamiの厳密な分類群・核系統樹と遷移史、(3) aza3の同一植物／操作群の生態的結果、という**独立な観察単位と測定法を保持すること**。単純な学名一致だけで異なるデータの個体測定を合成しない。
